# BPD-NC-12: the low-target-gradient information frontier

**Prospective source-only registration, 18 November 2026 UTC.** This document must be committed before NC-12 experiment code, model initialization, first source smoke, or any NC-12 data generation. Previous NC-10/11 model roots and negative results are design context only.

## Scientific question and information accounting

NC-11's cross-model score-Jacobian Procrustes failed causal transfer against a directly estimated target rank-four projector using the **same 128 target gradients**. NC-12 prospectively measures whether a source-trained rank-four subspace becomes useful when the target supplies only **q ∈ {4,8,16,32}** score-gradient rows.

Both source-assisted transfer and the direct target-only comparator receive exactly **q B-model score-gradient rows** at each comparison budget. They also receive the *same* **128 paired positive-context, unlabeled A/B activation examples**, giving both methods the same target activation information. The transfer method alone receives a pretrained A rank-four projector and A score gradients; this additional **source** information is a reported asymmetry, not a source-free target estimator. A regularized alignment prior is required because with q<20 the Jacobian cross-covariance has rank at most q and unrestricted 20×20 orthogonal Procrustes is not identifiable.

## Models, roots and data seals

- Eight fresh independently initialized model pairs **roots 1200–1207**; excluded engineering smoke root **1199**. Model A at `root`, B at `root+100000`; separate 384-update Adam optimizers, LR .005, batch 128, separate 2048-case Gaussian training streams `sample_x(root,1)` and `sample_x(root,11)`. The same freely trained 20D `DenseLooper` runs **four genuine nonlinear weight-tied physical `mix` steps**, with no planted stage support.
- Task A: sign(x0) for context `x4>0`, else sign(x1). Task B: sign(x0) for context `x4>0`, else sign(x2). External labels are allowed for model training and **final evaluation only**.
- For each pair, use **1024 A-discovery examples** (`split=2`), **512 calibration-pool examples** (`split=4`), **1024 B physical-dose examples** (`split=6`), and **1024 untouched final labeled evaluation examples** (`split=3`). Discovery, calibration, physical-dose and held-out streams are disjoint. B's full 1024 gradients on split 2 may be computed **after** fixing all q-budget predictors, solely for an explicitly high-target-budget descriptive ceiling; they cannot influence alignment, q selection, gains, shams, or technical eligibility.
- Take the **first 128 positive-context** examples from the 512 calibration pool in original order; require at least 128. Compute **paired A/B native pre-`mix` read activations** on all 128 to fit one fixed per-pass orthogonal activation Procrustes prior `R_act,t`. Generate model-score Jacobian rows on the **first 32** of those 128 in original order, with A and B each evaluated on the same rows. Every registered budget uses nested prefixes of those 32 rows: q=4,8,16,32. **At most 32 B gradient rows are queried in the entire primary experiment** (reused across nested budgets). Treat a gradient row as the 20D prewrite gradient at all four passes of a *single* input; four passes do not count as four independent queries.
- Clean external-label competence ≥85% separately for A/B and shared/private context, B and A dense mix weight fraction ≥90% (absolute entry ≥1e-4), exact native BPD full-ones closure at four outputs (max absolute logit ≤5e-5, float64 KL ≤1e-7, relative physical residual ≤1e-4). One **trained model pair**, not models/cases/passes/shams, is the independent inference unit.

## Source projectors, regularized transfer and equal-budget direct B control

- Discover source A projector `P_A,t`, **rank four per pass**, as top eigenspace of the uncentered final-A-model-logit gradient second moment from 1024 A discovery inputs. Model-only B q-budget direct projector `P_B,q,t` is top rank-four of `G_B(q)^TG_B(q)/q`, where each B Jacobian row is normalized to unit length before the moment. No external labels enter. All projectors require λ4>1e-12 and eigengap λ4/max(λ5,1e-12)≥1.001 at each pass. Preserve each failed root-budget `UNIDENTIFIABLE` without selecting alternate directions.
- Compute unit-normalized A/B `d(final_model_logit)/d(physical_prewrite_read)` matrices `G_A(q),G_B(q)` from the same nested q calibration pairs. Zero norm ≤1e-12 blocks the arm. The **activation Procrustes prior** `R_act,t` is the orthogonal polar factor of the paired 128-case prewrite activation cross-moment, fitted before gradient discovery on calibration.
- **Frozen source-assisted estimator:** `R_{q,t} = polar((G_A(q,t)^T G_B(q,t))/q + 0.05 R_act,t)`, with polar from the exact full-rank SVD `U V^T`. The `0.05` ridge is fixed *before* NC-12 data. The activation prior makes the q<20 alignment defined in unobserved directions. Report condition number, minimum singular value of the regularized cross-moment, fit residual and orthogonality. Transport `P_{A→B,q,t}=R_{q,t}^T P_A,t R_{q,t}`.
- **Activation-only control:** `R_act^T P_A R_act`, with the *same 128 B activation rows* and zero B gradients. **Permutation control:** apply a one-row cyclic permutation to `G_B(q)` within each budget, with unchanged activation prior and ridge, then transport the same `P_A`. This preserves all target-gradient values and available information, breaking case pairing. The fixed cyclic shift prevents a q=4 accidental identity permutation.
- **Target-only control:** `P_B,q` uses the same q B Jacobians and all 128 B activations remain available as unused input. It does not access source A model or its large gradient-discovery pool. A full 1024-B-gradient projector is only a **descriptive high-budget ceiling**, and is scored after all primary source-only choices are frozen.
- Exact gauge check: transport `P_{A→B,32}` through an independently seeded orthogonal **B factor chart** and check native vs rotated physical write operator relative Frobenius error ≤1e-4 and full closed-loop logit discrepancy ≤5e-5. This is an exact within-B code diagnostic, not evidence of A/B model equivalence. A zero B readout head must produce exact zero source Jacobians.

## Physical dose, negative controls and held-out endpoints

- Calculate each q transfer project's retained **physical B-`mix` write RMS** on 1024 clean dose-only inputs. For the **target-only, activation-only and permuted q comparator**, set `alpha = RMS(transfer_q)/RMS(comparator)` from the same dose-only pool; admit only if every raw alpha lies in **[0.5,1.5]**. Apply that frozen comparator-specific gain to all four passes. Transfer gain is 1.0. Report raw gains, actual physical write RMS, and realized closed-loop write displacement. Do not clip a failed alpha and call the root-budget eligible.
- At every q, generate **2048** seeded fixed-angle rank-four target physical sham projectors around the transported projector using `θ∈{0.45,0.65,0.85,1.05}` radians. Select the **first eight** candidates within ±15% of the source-only retained physical write RMS, independent of all held-out inputs or labels. Each q has its own fixed seed; shams are correlated within a model pair. Record selected proposal indices and admitted counts, with failures blocked. A q arm failing this gate is ineligible; do not enlarge its proposal budget retrospectively.
- Evaluate on the untouched 1024 input split 3 only **after** freezing the complete nested q budget family, activation and ridge maps, B-only projectors, physical gains and shams. Primary readout is B external-task **shared-branch true-label NLL** on `x4>0`. Also report private-branch NLL, clean/arm task accuracy, four-pass Bernoulli KL(clean||kept), full-model clean task confidence, source A own-projector fidelity and local physical displacement.
- All causal arms use the actual native BPD `BPDModel/TiedComponentLinear` `override_read` interface at all four shared physical recurrent passes with zero residual bypass. A source gradient detector and a zero-head detector must be blind to B external-label oracle.

## Registration, multiplicity and scientific gate

The immutable **16-comparison family** is the four q budgets × four root-level paired directional tests:

1. **Source transfer beats direct B estimator:** `NLL_B,shared(P_B,q,matched_gain) - NLL_B,shared(P_transfer,q)`; require familywise bootstrap **lower >+0.01 nats**.
2. **Source Jacobian alignment improves activation-only:** `NLL_B,shared(P_activation,matched_gain) - NLL_B,shared(P_transfer,q)`; require **lower >+0.01 nats**.
3. **Matched physical shams:** `median_8 NLL_B,shared(P_sham)-NLL_B,shared(P_transfer,q)`; require **lower >+0.02 nats**.
4. **Absolute task fidelity:** `NLL_B,shared(P_transfer,q)-NLL_B,shared(clean_B)`; require familywise bootstrap **upper ≤+0.05 nats**.

For every comparison, bootstrap **whole independent trained model pairs** with 4096 fixed-seed resamples and **99.6875% two-sided Bonferroni percentile intervals** (0.05/16 per cell). A q-specific positive engineering claim requires **8/8 technically eligible model pairs** and all four q-specific family-adjusted gates. **Primary rank-budget decision** is the *smallest q in {4,8}* meeting all four gates; if neither, `NO_LOW_BUDGET_WIN`. Any q=16 or 32 performance is descriptive with the same registered family, and cannot rescue the low-budget primary gate. Preserve all tested budgets, failed source admissions, and their per-root effects.

Development verdict `ENGINEERING_LOW_BUDGET_TRANSFER` requires an admitted q=4 or 8. Otherwise `ENGINEERING_NULL_OR_INELIGIBLE`. All scientific failures remain green CI with immutable original receipts. Eight roots are exploratory for transfer across broader model families. **No confirmation population is registered**, and an independent ≥59-root sham calibration plus exact EvalMath mechanistic-power preflight must precede a new confirmatory study. Protected ARG-03-N, AMM-03 and all unrelated seals remain untouched.

## Interpretation boundary

NC-12 tests whether **additional source mechanism information** compensates for scarce **target gradient queries**, with target activations from 128 paired unlabeled cases held constant for all methods. It cannot establish that A and B have a unique matching causal representation, that natural language model neurons share identifiable circuits, or that results extend beyond a constrained synthetic two-task family. NC-10/11 negative first-run results must remain intact.
