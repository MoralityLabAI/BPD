# BPD-DT02-A: CI CPU trained Attention-TRM and limited recurrent steering

**Frozen development/engineering protocol, November 18, 2026.** Parent [BPD-DT02 issue #98](https://github.com/MoralityLabAI/BPD/issues/98). Stage 0 [BPD-DT01 PR #96](https://github.com/MoralityLabAI/BPD/pull/96) provides exact task oracles, host-only hidden ending labels, and the general full-readout depth-contract. This stage runs a **small native Attention-TRM**, trained in hosted CPU CI with explicit bounded budgets. It is not the pretrained 7M Sudoku TRM, a trained official ARC-1 solver, or a root-calibrated BPD mechanism discovery.

## Registered architecture, data and splits

Use actual \`mechinterp.loopscope02.scripts.trm_sudoku.PureSudokuTRM\`, with **hidden size 32, four attention heads, one tied TRM block, one H-cycle and one L-cycle per ACT step, puzzle-prefix length 1, sequence length 16**. All physical attention/MLP layers are the real shared TRM implementations. Train **three independent native mini-TRM checkpoints per excluded root 901/902**, one per family, with AdamW LR 0.004 and gradient clipping 2.0. Each model receives 64 updates of 16 independent training examples per update. At each training step, the same model and physical matrices are executed through depth **2,4,6**, with categorical CE averaged across these depths. **Depths 8 and 12 are excluded from training** and used for development extrapolation evaluation only. CPU threads: two.

- **Sudoku4:** exact 4×4 uniquely solvable host-generated puzzles, six removed givens, full solution target verified by an independent Sudoku oracle. Inputs are 16 integer tokens; all 16 predicted cells are scored. Report full-board exactness, cell accuracy and Sudoku legality, including 0% outcomes.
- **Synthetic ARC-style:** 4×4 transformation programs, training rules \`flip_h\` and \`recolor_1_2\`, evaluation rules \`rotate_180\` and \`fill_zero\`. Distinct *program* families; output-cell exactness and whole-grid exactness. **No official ARC-AGI-1 JSON is evaluated by this CI job.** Stage 0 preserves the separately offered local official ARC JSON interface.
- **Hidden ending storyworld:** model receives only public state features (day, trust, evidence, stability, token, terminal flag and action count). Expert supervised action targets follow a deterministic public-state policy; host secret-cause and ending labels are never model inputs. Report action accuracy on independently generated public states and 12-step closed-loop episode success, where final endings are revealed only by the host after terminal transition. Different deterministic world roots define train and eval cases.

Two previously used **engineering seeds [901,902]** only, with independently seeded training and evaluation example streams. Every example seen is generated by code from the Stage 0 world helpers. All generated, exact-task and source-program family results remain separated.

## Recurrent state steering diagnostic and source-dependent limitations

For Sudoku4 only, use eight independently generated donor-recipient pairs from different world roots, and intercept the actual native TRM \`z_H,z_L\` recurrent state after ACT depth 2. The protected current observer is the **entire 11-token physical LM-head softmax at each of the 16 board positions**. Compute the full-head row-space kernel by float64 SVD. An injected state edit projected into this nullspace and zeroed over the prefix should conserve every current normalized vocabulary probability to tolerance ≤1e-6, before further ACT recurrence.

Compare no edit, full protected-dark donor state difference, and a rank-eight *physical attention output weight-SVD* state direction followed by exact readout-kernel projection. Evaluate donor-model cell agreement, board agreement, logit MSE and physical dose at depths **4,8,12**, with all eight pairs retained.

This state-space physical SVD steering diagnostic is **not a trained BPD V/U sparse-factor intervention**, does not use a full signed multi-cell task-Jacobian-matched null, and supplies no independent true task improvement claim. It verifies a native recurrent intervention surface on the actual TRM architecture, and probes whether a depth-4 effect persists at 8/12.

## Engineering and science boundary

Source-sha lock before running the registered hosted job. CI runs six source/native smoke tests, then two roots × three trained models, with 64 examples per family/root in evaluation and 12-step storyworld terminal rollouts (16 worlds per root). Archive raw JSON and model \`state_dict\` SHA-256 in the receipt; **do not upload full model checkpoint files** during this pilot. Report nominal max action/logit readout shape and model parameter count. Require finite training loss, valid inputs/targets, frozen evaluation depth roster and exact physical readout conservation; report all task failures.

This is a small engineering and baseline competence study; no claimed solution to Sudoku9, real ARC-1 benchmark, identifiable BPD component, robust extrapolating mechanism, 95/95 calibrated effect, or neural LDT red-team. Native pretrained 7M adapter remains a separately gated future stage requiring an independently verified model checkpoint and more compute. All prior SF/CGC negatives and the ARG-03-N sealed 168-case test remain unchanged.
