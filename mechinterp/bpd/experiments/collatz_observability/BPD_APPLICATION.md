# Applying the exact fixtures to BPD

## Immediate use

Use BPD-COL-01 to validate the observer and intervention machinery with
complete finite answers. Its declared population and receipts are public
development material. It adds a source of exact calibration cases to the
existing [BPD experiment program](../../README.md).

| BPD component | Exact fixture | Measured endpoint |
| --- | --- | --- |
| Observable quotient diagnostics | Conserved arithmetic `q` | Zero self-closure defect, with basin sufficiency scored separately |
| Visible Gap and delayed observation | `d=13`, `r=(q,c)`, states `1` and `5` | Equal current readout and different next branch |
| Reachable donor and sham checks | `d=73`, recipient `1`, donors `9` and `37` | Equal physical dose, equal current readout and basin, differing future response |
| Target-aware compression | `d=29`, states `5` and `9` | Equal infinite branch trace with different basin labels |
| Gramian/rank instrumentation | One-hot recurrence at `d=13` | Exact rational rank through each declared horizon |
| History-based state estimation | Ordered branch-and-valuation prefix | Exact modular decoder and explicit observation cost |

The [causal quotient note](../../../../papers/shared_weights_dark_fibers/CAUSAL_QUOTIENT_ARG03.md)
already defines the current and trace information sets. The new fixtures
make those definitions enumerable. [EFD-01](../efd01/README.md) provides the
physical current-kernel and delayed-rank instrumentation; the one-hot example
gives it a specified embedding with exact expected values.

## A native adapter experiment

A later adapter can expose `W`, the complete categorical observer `O`, legal
initial states and the continuation operator `W^h`. The initial calibration
should recover all registered positive and null cases before fitting a
learned recurrent transition.

For a trained model, freeze the physical checkpoint and candidate component
selection on development roots. First verify the base transition and
whole-trajectory task accuracy. Then perform same-pass donor interventions,
continuing the recipient with the complete state and the same input contract.
Current output equality and later output changes have separate records.

The repaired [DT03 contract](../depth_steering_gym/DT03_REVIEW.md) supplies
the relevant native interfaces:

| Native helper | Calibration target |
| --- | --- |
| `flat_observer_jacobian` | Every coordinate of `O W^h` |
| `physical_task_gramian` | The declared finite-horizon linear observability operator |
| `whole_case_recovery` | Exact equality of the complete registered output word |
| `validate_delivered_sham` | Current readout and delivered physical dose |
| Full H/L continuation | Same complete recipient state apart from the registered intervention |

Full reachable donor replacement establishes a state-level effect. To test a
BPD component's role in carrying that effect, follow
[CQ08](../../theory/cq08_nuisance_mediation/README.md): hold the natural donor
state fixed across arms, then intervene on the selected component at a later
visit. Include matched component masks and report every admitted and rejected
pair. [CQ07](../../theory/cq07_reachability/THEORY.md) explains why an arbitrary
low-rank patch needs its own reachability check.

## Information available to the monitor

For an information-limited observer task, keep the initial seed private and
declare the hidden-state sampling process. All paired cases share public
parameter `d` and the same pass. The current monitor receives `(d,q,c)`;
each additional branch or valuation observation is charged explicitly.

A conventional arithmetic task can supply `(d,n)` to the model. Under that
input contract, compare bounded algorithms and learned computation because
the initial state determines the future. The source experiment should record
which contract it implements before interpreting a Visible Gap.

An offline future-equivalence partition is useful for selecting cases and
checking outcomes. A deployable trace cache receives only observations that
have already occurred. Keep their evaluation endpoints explicit.

## Depth, cycles and training controls

Randomize the starting cycle phase and match comparisons at the same pass.
Record first divergence, full observation-word error, eventual basin and
phase within a cycle. A final readout can agree after a transient effect;
two phase-shifted states can disagree for many passes while sharing a basin.
The existing
[INK-BPD-03 study](../inkling_routing/RESULTS_INKBPD03_GATE_DEV_20261121.md)
provides a native synthetic example of repaired single-pass damage and
persistent all-pass damage.

Train-only candidate selection should be followed by unseen parameters and
depths. Keep all seeds and trajectories sharing one parameter in the same
split, and audit scaled copies before any train/test claim. All parameters in
the exact receipt are already exposed. The
[COL-OBS-02 protocol](https://github.com/MoralityLabAI/LoopedTransformers/blob/b14a51015996f0dee81ef033e2e198d9f84951b2/research/collatz_observer_gym/NEURAL_PROTOCOL.md)
specifies root-level inference, matched finite-capacity controls and a
mechanistic-power preflight for a later neural study.

Compare a selected physical BPD block against the complete donor effect,
equal-rank and equal-dose interventions, and signed task-sensitivity-matched
controls at the same horizon. Check factor-gauge changes and independent
decomposition refits. Report whether an effect improves independent task
correctness as well as whether it recovers a donor model's behavior.

## Evidence attached to this change

The new code establishes exact facts about the enumerated arithmetic states
and specified one-hot representation. The receipt includes finite donor
contrasts, an all-horizon null certificate and exhaustive autonomous observer
refinement. It contains no trained BPD model result.

Native factor mediation, cross-model transport and intervention-preserving
compression remain experiments with their own targets and gates. The
[NC12 transfer result](../../../../papers/shared_weights_dark_fibers/BPD_TRANSFER_ADDENDUM_20261118.md)
and earlier BPD outcomes retain their recorded scope. This fixture supplies
calibration evidence for extending those methods.
