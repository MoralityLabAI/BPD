    T_i = max_{j=0..7} |NLL(sham_ij) - median_{k=0..7}NLL(sham_ik)|.

The eight shams are generated without external label access and matched to the root's DP12 pass ranks and clean physical retained-write RMS. Root 12047's original eight matched sham task NLL values included a high of **0.593118**, against other local orientations between **0.149991** and **0.442392**. The 95/95 statistic is **roughly 9.15×** the fresh observed mean same-rank allocation effect A=0.032142. It is a deliberately conservative *rootwise maximum* floor. It is not a distribution-free critical value for the 32-model-root sample mean, and its high value does not establish that the true expected allocation benefit is zero. It establishes the outcome of the prospective EvalMath resolution test under this particular registered sham-null definition.

## Causal interpretation and the next permissible action

The calibration is scientifically informative. **Physical pass-specific rank allocation retained a positive average final externally labeled task benefit over flat3 and source-dose-matched flat3 on new recurrent model roots.** The source-local shams had a much wider model-root worst-orientation envelope, so the registered conservative EvalMath mechanistic-resolution gate blocked release of the provisional 32-root confirmation. This is a **power/calibration hold**, distinct from an empirically refuted mean allocation benefit.

The source-only DP proxy is first-order and may ignore cross-pass Jacobian changes. Local source physical shams match rank tuple and retained clean-write RMS, but task gradients and future edited-state distributions can vary across orientation. The largest rootwise sham NLL deviation is not commensurate with the uncertainty of the root-mean A, which suggests a later prospective redesign should distinguish rootwise effect-size tolerance from the null distribution of the exact **aggregate estimand**. A separately registered experiment could predefine a causal contrast that matches physical write geometry **and task-relevant derivative dose** on source data, while retaining independent external labels for scoring. Any recalibration must use **new independently trained model roots**; the original 59 roots are now exposed calibration observations.

Scientific confirmation remains **sealed**. Zero independent 32-root confirmation models were sampled or trained in FC01. Original NC09 Fixed12, NC10, CQ/ARG/AMM and all preceding BPD sources remain unchanged. New confirmation requires a separate prospective protocol, a calibrated null and EvalMath power admission independent of the protected readout.
