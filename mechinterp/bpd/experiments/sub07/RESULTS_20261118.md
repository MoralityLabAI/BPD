## 5. Mechanistic reading and next candidate

The oracle successfully repaired the **external information-depth problem** from SUB-06. A six-token, order-sensitive label demands information unavailable from early prefixes, and 3/8 GRU sources reached 95–99% heldout accuracy with robust group competence.

The mechanistic hypothesis is more demanding: correctly timed source fitting should produce a substantially better rank-20 next-state quotient than **an equally powerful wrong-clock source fit**. It did not. The eligible-root effect was two orders of magnitude below the registered +0.010 threshold, and five initial sources failed to learn the task reliably.

The two unresolved experimental weaknesses suggest a new *prospectively registered* development stage:

1. Establish competence reliability with a higher-capacity or explicitly curriculum-trained source model, using new seeds, frozen architecture and strict minimum contextual accuracy before recurrent-causal analysis.
2. Increase causal identifiability with a richer multi-output or role-structured sequential state task. The current oracle label reveals only one bit of the two-bit state, leaving hidden-state directions and clock assignments underdetermined by the endpoint. Test whether a task requiring several intermediate invariants or noncommuting transition-specific readouts yields clock-dependent causal geometry. Preserve fully source-fitted wrong-clock controls with equal optimization budget.
3. Measure causal root-level effects and strongest-null variation on new development models before deciding on any new 59+ model calibration.

This remains a **synthetic mechanistic engineering failure** with a mathematically exact information-depth oracle. It provides no evidence for biological substrate interchange or phenomenal continuity. The original SUB-05 PASS and SUB-06 FAIL remain separate records.
