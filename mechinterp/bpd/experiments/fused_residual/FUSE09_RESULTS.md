## Mechanism
New cache_pgd_mask_residuals=False flag requires explicitly enabled step_exact policy when true. Native inner PGD calls with detached CI values use autograd.grad only on source leaves, and their losses are discarded. At fixed weights residual D=W-(VU)^T is constant with respect to source masks. Returning the same detached D preserves d(input)/d(source), native F.linear input derivatives, mask and norm dependence. A factor-gradient objective would be incorrect if this detached graph were included: omit factor derivatives only in private source-only scope. Final adversarial retained graph, clean capture/calibration, faithfulness and evaluation remain native. Each stochastic or clean-window training request still creates independent residual VJP. Share one pool with fixed selected sites and exact planned call count; cap unique cached detached primal storage across outstanding graphs. No eviction or replacement, verify identities/versions and storage, restore methods, close pool before optimizer mutation. Mask-only values have no backward seal hook; rely on native inner PGD caller consuming only source gradients. Unsupported calls bypass; checkpoint/reentrant/concurrent/higher-order/external writes outside contract. No default switch.
For T closed-loop calls per eligible rollout with K=2 inner PGD iterations, eligible count N=3T per site. Original cost per site N*D_in*C*D_out. Selected primal saves (3T-1) times reconstruction cost vs (T-1) for stochastic-only. With 4 sites and n selected, total eligible reconstructions 12T-n(3T-1).
