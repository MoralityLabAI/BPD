# FUSE-02B | Post-pilot cancellation guard diagnostic
Registered after FUSE-02 ordinary/stress results, before this fresh diagnostic. Preserve FUSE-02 negative results. Prototype an inexpensive operand-amplitude guard, outside the default native wrapper. For supported CPU float32, compute fused candidate and pre-bias operands y_d=dY, z_u=zU, mean residual term. Reject if any nonfinite or if a per-token cancellation proxy max(abs(y_d)+abs(z_u)+abs(mean term)) exceeds 64*(max(abs(candidate))+1e-3), or if max(abs(V)) or max(abs(U)) exceeds 2.0. This is a heuristic support restriction motivated by observed high-factor-scale cancellation, not a certified numerical bound. If rejected execute original native branch, preserving full autograd. Reference branch used unchanged. Compare original, unguarded fusion and guarded fusion on fresh seeds 2902001..2902032; D=64 C=32 N=8, scales 1,10,100,10000, target W=(VU)^T for cancellation fixtures, and ordinary independently drawn target W; mask all zero or soft. Report tensor parity pass rates, false admissions/rejections (forward tolerances 5e-5/5e-4), no physical runtime or universal gradient/forward guarantee. If any admitted failure, no promotion, retain only explicit experimental flag. Existing near-eps guard separate. This diagnostic is not a trained model benchmark.
