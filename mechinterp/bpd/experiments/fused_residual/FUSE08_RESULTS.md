## 1. Admission and mathematical contract
Existing opt-in flag cache_single_backward_residuals=False stays default. Existing first_fit policy remains default when opted in. New residual_cache_policy values exact and step_exact. Eligible contexts remain only stochastic reconstruction and clean-window adversarial reconstruction, each included once in the joint backward. Closed-loop PGD inner/final branches, clean/calibration, evaluation, faithfulness loss/warmup stay reference. Plan in stable BPD module_order using original dimensions, rank and actual planned passes. Exclude unsupported CPU dtype/layout/precision/autocast/grad configurations and trainable target weights. Frontier overflow returns reference with explicit reason; empty plan similarly. No config or state-dict changes; original components.py c0906e73a993738871812572e267e2ef5f9595d3, independent adjoint b44b1702bc235790adf7d20f4abf022da049ef67 and knapsack selector ece08080405b6006e6de63c3b253e174bfd98461 unchanged.

Per rollout exact: with t calls at site i, w_i=4*D_i*O_i bytes, v_i=(t-1)*D_i*C_i*O_i MACs. Per step exact: with K eligible rollouts and identical t calls each, use T=K*t and v_i=(T-1)*D_i*C_i*O_i. Exact Pareto knapsack maximizes saved reconstruction MACs under declared cap, as proved in FUSE07. K separate caches save K*(t-1) times the reconstruction cost, one shared cache saves K*t-1 times it. Difference K-1 reconstructions/site. For K=2,t=3, ratio5/4. General heterogeneous planned call counts could replace T by sum across eligible rollouts if fixed and known; current adapter contract assumes one call per wrapper per planned invocation. Arithmetic proxy, not a runtime guarantee.

StepResidualPool keeps fixed selected sites with one detached original residual allocation each; no replacement or eviction. Each request invokes frozen _Primal in residual mode, so separate native-equivalent factor adjoints, no shared cotangent aggregation. The code verifies unique cross-site storage addresses, expected storage byte size and that each custom adjoint output aliases its cached primal. Between scopes retain same primal, check identity and version/shape/stride/dtype/device/requires_grad of W,V,U and primal version, hold strong references to original parameter/buffer tensors. Detect mutation and poison pool; no reuse of a new value while older graphs exist. Detect backward while a forward scope active, seal pool when cached output receives gradient, refuse later scopes after sealing. Restore methods in finally, close pool after joint backward before optimizer mutation, finally also closes on exception. Each scope logs calls, misses, hits, cross_scope_hits, backward nodes and stable pool-local slot IDs; pool receipt records peak and release. No concurrent/reentrant/checkpointed/higher-order/unsafe .data or external storage mutation support. Hook diagnostic does not constitute universal autograd graph-lifecycle proof. The cap covers unique detached cached primal storages including aliases saved in outstanding graphs, not other residual tensors, activations, autograd saved tensors, optimizer, Python metadata or total RSS. Exact per-rollout mode caps one scope only; two outstanding exact scopes can retain two different cached primals for each selected site (up to twice cap), whereas step_exact keeps one per site. Closing removes pool-owned references, not arbitrary external graph references. No physical peak-memory measurement. No production default change.
