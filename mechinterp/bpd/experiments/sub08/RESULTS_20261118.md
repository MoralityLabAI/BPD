partition. Scientific status is **CAUSAL_STUDY_NOT_RUN**. This phase contains
zero hidden-state interventions and zero measured causal root effects.

## What the independent units support

Eight independently initialized and trained models are the statistical units.
The 1024 heldout sequences are shared across roots, giving 8192 model-sequence
observations and 1024 distinct heldout inputs. The observations within a model
are repeated measurements for the training-reliability question.

The exact two-sided 95% binomial interval for the model pass probability is
**[63.0583%,100%]**, conditional on independent roots from this frozen setup.
Eight observed successes satisfy the engineering criterion while leaving a
wide interval for future-seed reliability. Generalization across different
sequence partitions or different tasks was unmeasured.

The source changes from SUB-07 included the richer target alongside a wider
hidden state and a longer training budget. This study measures their combined
setup; the contribution of each change remains unseparated.

## Exact four-class task

Initial state is (a,b)=(0,1). The six tokens are drawn from X,S,C,R, with
X(a,b)=(a xor 1,b), S(a,b)=(b,a), C(a,b)=(a,b xor a), and R(a,b)=(a xor b,b).
Tokens execute left to right. The target is class `2*a6+b6`, which records the
entire final state. The full domain has `4^6=4096` ordered sequences.

The subset ceilings use the actual empirical class counts within that subset.
They supply the valid comparison for the heldout model scores. The population
values have a different sampling measure and cannot be used as hard ceilings
for every finite subset. These are exact optimal bounds for the stated
restricted features, derived using the oracle labels.

The final trained head scored 30.17578% to 30.46875% when evaluated after only
two tokens and 36.91406% after four. Those truncated-head diagnostics remain
below their exact subset ceilings. They measure the existing head after a
partial rollout; separately trained optimal prefix classifiers were unnecessary
because exhaustive counting already supplies the best possible feature bounds.

An order witness is XXSSRC, whose final state is (1,0), and XXSSCR, whose final
state is (1,1). Their token counts agree. This exact arithmetic establishes that
the restricted input features lose task information. A universal computational
depth lower bound for architectures that see all input positions was not tested.

conditional entropy and split digest.

## Training and readout contract

The fixed permutation uses NumPy default_rng(246810), with 2048 train sequences,
512 validation sequences,512 reserved-dose sequences and 1024 heldout sequences.
All partitions are sequence-disjoint. The deterministic oracle labels are public.
Prospective model behavior was unexposed during pilot selection. Reserved-dose
model outputs remain uncomputed.

Training uses final-class cross entropy with Adam at learning rate 0.003,
batch 128 sampled with replacement, and a dedicated minibatch generator seeded
with root+44. The shared GRU starts from a zero hidden state and processes one
four-way one-hot token at each step. There is no intermediate-state supervision.
The fixed 2400-update budget has no early stopping. Both phases ran under the
same CPU float32 environment: Python 3.12.14, Torch 2.5.1+cpu, NumPy 2.3.5,
one Torch thread and deterministic algorithms.

The original design grid took 58.735 seconds and the prospective cohort 49.910
seconds in this environment, excluding artifact packaging and the read-only
audits. These are execution receipts for this host and workload.
