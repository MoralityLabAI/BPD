# AMM-11: transferred BPD strategy memory versus a strong cosine geometry null

**November 18, 2026. Prospective, source-locked DEVELOPMENT finding. Mechanistically meaningful incremental transfer over cosine: FAIL.** On 64 new independently trained six-dimensional rank-three recurrent models, the global ridge memory gained +1.935 percentage points over an explicit \`argmax cosine\` physical-rule comparator. The independent-root sign test detected a directional effect, but the whole 95% interval lies below the **preregistered +8 percentage point meaningful-effect floor**. The corrected EvalMath planner returned **\`REDESIGN_OR_PILOT_ONLY\`**, and the preregistered factor-fidelity admission veto also failed. All 128 reserved AMM11 confirmation model roots remain sealed. Original AMM03–09R1 and ARG03-N protected populations are untouched.

## Why this specific adversary matters

AMM09R1 independently observed a positive +13.62pp global memory benefit over the training-selected fixed pooled mask. The selection-exposed [AMM10 study](../amm10_exposed_dissection/RESULTS.md) showed that much of the learned policy's action ranking is explained by the cosine between each equal-dose component write and the known first-pass donor state displacement. Pure \`argmax cosine\` achieved 38.51% on the exposed, root-held-out TRAINING data, near the full ridge's 40.14%. These data selected the **AMM11 geometric competitor**, and have not been reused as AMM11 model populations.

The question registered in [PROTOCOL.md](PROTOCOL.md), commit \`90a48452ce5583f8acf0e5f1a8216e8c45eb216a\`, is **whether cross-model learned causal-response memory exceeds this hand-designed physical direction rule by at least +8pp on newly trained models**. The preregistered planning target was +12pp. A significant but small advantage is evidence of an incremental predictive signal; it does not satisfy the claim of a physically meaningful learned mechanism over the strongest available analytical geometry.

## Scientific task and matched interventions

Every independent AMM11 root trains a distinct 6D rank-three three-pass weight-tied physical recurrent teacher from external three-pass source targets and a separately initialized BPD V/U decomposition fitted to teacher trajectories. Donor-recipient inputs alter one first-pass nuisance coordinate and the two delayed task-relevant coordinates. The target is the **external source-defined donor (y₂,y₃)**, fixed prior to fitting and excluded from every policy.

A policy chooses one of six masks \`(0),(1),(2),(0,1),(0,2),(1,2)\`. Each mask yields a canonical factor write projected into the kernel of the *current readout*, then renormalized to the **identical within-pair full-donor first-pass L2 dose**. The model continues two further trained shared passes; success requires both delayed readouts within tolerance .18 of the two donor source targets. Equal-dose random-dark and no-patch sham controls are retained; full donor state replacement is an **equal-norm but immediately visible ceiling**. The full three-factor mask is forbidden in this study.

Policies all receive identical geometry, 18 source-safe candidate readout/patch features and 14 unlabeled readout measurements per donor case. The strong analytical \`cosine\` comparator chooses the mask maximizing the feature-column-14 cosine between the equal-norm current-dark patch and the *observed full donor first-pass displacement*. That physically available donor state reference is an important synthetic-world information assumption. The cross-model \`full_memory\` pays an additional amortized 64-training-model supervised corpus. Each new root has 16 calibration donor pairs and all local policies share the same **96 noisy reported candidate successes** with independent 20% label flips. The separate \`compact_memory\` fits only the ten feature columns \`[0,1,5,6,7,8,9,10,11,14]\` from the same training corpus. All active strategies have the same six physical action choices and donor/recipient observational budget.

## Scientific admission, physical integrity and fidelity

The preregistered +8pp meaningful effect competes against a matched 95/95 independently rooted sham tolerance: the **same frozen cosine rule** evaluated on 512 original test and 512 disjoint repeatability donor pairs in each of 64 separately trained models. The maximum absolute within-root difference was **38/512 = 0.07421875** (7.42pp), an upper bound on the 95th population quantile with at least 95% confidence. Measurement resolution was 1/512. The mechanistic floor is therefore **max(.08,.07421875,1/512)=.08**.

Corrected pinned EvalMath \`MoralityLabAI/EvalMath@6d9c28dbe8e4c42b3fba76ae7adb84aed9f0921a\` returned **\`REDESIGN_OR_PILOT_ONLY\`**, reason \`pilot_effect_not_above_mechanistic_variation_floor\`, with observed primary +.019348. Its nominal planning power for hypothetical +.12 cannot substitute for the measured gain. The positive adjusted root-sign result cannot override this floor.

A separate preregistered SOURCE fidelity gate also fails: **55/64** development model roots passed the fitted teacher MSE ≤1e−4, BPD three-pass task MSE ≤.02, relative weight reconstruction error ≤.10 and both singular gaps >.01. The minimum was **56/64**. The nine flagged roots remain in every intention-to-treat score and independent-root inference. Audit-only six-mask per-case best-action headroom over cosine was **14.752pp**, above the >=8pp minimum; it uses forbidden heldout test labels and is never a policy. Maximum active same-dose L2 error was **4.7684e−7**, and maximum immediate readout displacement **zero**; the native BPD three-pass parity and GL3 canonical gauge tests passed excluded engineering.

**Scientific admission: FAIL. No protected confirmation population has been scored.** The experiment has no confirmation CLI. All 128 AMM11 confirmation roots and all earlier AMM03–09R1 and ARG03-N protected tests remain sealed.

## Interpretation and next experiment

AMM11 provides new-root evidence of a **small, directional extra predictive contribution from fitted strategy-memory** beyond a physical donor displacement alignment rule. The effect is below the registered meaningful mechanistic floor and cannot justify an independent confirmation claim. The original AMM09R1 large gain over pooled masks survives as its separately registered finding, while the present stronger null explains much of that phenomenon. Because the task permits a first-pass donor reference state, the cosine control has access to a powerful synthetic physical direction signal, which may have no direct analogue under genuinely hidden neural-state interventions.

The next useful study should change the substrate rather than chase another tiny same-instrument lift. A **prospectively registered nonlinear recurrent/TRM BPD task**, with the first-pass donor-state information budget explicitly declared and a physical cosine rule still present, would test whether transferable learned intervention strategy persists after source targets and factor geometry become more entangled. Retain root-balanced cohorts, equal physical dose, verified native model calls, a strong pooled control, a 95/95 sham floor, and a separate sealed confirmation population. Do not retroactively tune the AMM11 sources or re-open earlier protected roots.
