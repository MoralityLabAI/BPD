# BPD-NC-09: cross-task transfer of recurrent causal subspaces

**Prospective protocol; 2026-11-18.** Freeze this file as a source-only GitHub commit **before** experiment code, new model initialization, discovery data, or held-out evaluation. Following NC-05 (minimum eligible full-gain rank four), NC-06 (rank-three norm weighting failed its added-value gate), NC-07 (KL-selected variable rank failed its original compression/admission gate), and the concurrent NC-08 pass-budget study. This is a new scientific question and a new root population.

## Question

A rank-four BPD subspace recovered on one task might preserve a *shared computation* on a related task, while omitting a task-private computation. Test **A-to-B causal transfer within a jointly trained physical recurrent model**, using task A's model-logit gradients to discover its projector and external task B labels for the final outcomes. A and B share one context branch and require different input lanes on the other branch. This is a within-model cross-task transfer test; independent training roots support uncertainty. No transfer between independently trained hidden coordinate charts is asserted.

## Fixed paired tasks and architecture

- Each source example consists of four independent standard-Gaussian lane features `x0..x3` plus one independent Gaussian context `c`. Task A externally labels the sign of `x0` when `c>0`, otherwise `x1`. Task B labels the sign of `x0` when `c>0`, otherwise `x2`. The `c>0` subset is the **shared** branch; `c<=0` is the **private** branch. Each task receives a sixth fixed task marker, `-1` for A and `+1` for B. Input lanes, context, and both labels are generated independently of model weights. Only training and held-out scoring may query labels. Shared-branch task labels match exactly by construction on paired base examples.
- One jointly trained nonlinear, freely parameterized, weight-tied recurrent model with `encode=Linear(6,32)`, `pre=Linear(32,32)`, `mix=Linear(32,32,bias=False)`, `head=Linear(32,1)`. All weights initialize from each model root with native PyTorch initialization and all entries are trainable. Four tied passes use `a_t=tanh(pre(h_t))`, `w_t=mix(a_t)`, `h_(t+1)=tanh(0.60*h_t + 0.65*w_t)`, readout `head(h_(t+1))`. Initial hidden state is `tanh(encode(x))`. There are no planted sparse transition edges or teacher hidden-state oracles.
- Fixed Adam LR 0.005, **640 updates**, each minibatch has 64 independently selected task-A and 64 task-B examples; shared base training pool contains 2,048 Gaussian base inputs (4,096 marked task inputs). External labels supervise only training, not projector discovery. Hold out separate 1,024 base discovery cases and 1,024 base evaluation cases; for each split, create paired A/B task-marked examples with identical five continuous features. Both tasks use the same trained frozen physical weights at final evaluation.
- **Fresh engineering training seeds 900–907**; excluded-source engineering seed **899** for unit/smoke tests. No other seeds, confirmation data, or protected cohorts may be run under this protocol. All eight development roots are independently initialized and trained. Within-root paired examples and interventions are correlated repeated measurements, not independent roots.
- Clean task gate: model's held-out accuracy >=85% for EACH task and context branch, native shared physical `mix` density >=90% of weights with absolute magnitude >=1e-4, and at least 20% of negative-context paired examples have different A/B labels. If a gate fails, preserve the root receipt as `FAILED_TASK` and exclude it from the predeclared joint mechanism decision.

## Frozen projector, factor, and native causal protocol

- Fix projector **rank r=4** at each of four passes, independently discover `P_A,t` on task-A discovery inputs and `P_B,t` on task-B discovery inputs. Discovery uses **only the frozen model's final logit** (detached model-predicted sign gives a self-confidence gradient; the uncentered gradient second moment is sign-invariant), no external task label. Gradients are taken through the native physical `mix` output and re-expressed in its input read-coordinate basis. Compute full float64 `C_t=mean(g_t g_t^T)`, rank-four top-eigenspace projector, symmetry/idempotence, eigenvalue lambda4/lambda5 and gap.
- Preregistered numerical eigengap admission: lambda4 >1e-12 and lambda4 / max(lambda5,1e-12) >=1.001 at every pass, separately for tasks A and B. Any failure is `UNIDENTIFIABLE` with the exact spectrum retained.
- Intervene at all four passes on the **original native `BPDModel/TiedComponentLinear`** physical shared matrix, with complete closed-loop recurrence, using `override_read` and `read_override[t]=V @ (alpha*P_t)`, all 32 factors and `scale=0`. Bias-free physical `mix` weight reconstruction is exact: `V=I,U=W^T` in native coordinates. The randomized orthogonal factor basis `V'=Q,U'=Q^T W^T` must reproduce each physical `V P U` to relative Frobenius error <=1e-4 and held-out output logits <=5e-5, for both A and B projectors.
- Clean full-mask parity across all four logits, two task-marked inputs and both factor bases: max absolute logit difference <=5e-5, double-precision Bernoulli KL <=1e-7 nats, and relative physical weight residual <=1e-4. Any parity failure blocks causal interpretation.
- Absolute write energy equalization is discovery-only and target-task-aware: measure `d_A` and `d_B`, the retained **physical** write RMS of `P_A` and `P_B` when run on clean task-B discovery states. Compute source transfer gain `alpha_A=d_B/d_A`. **Admit only 0.75<=alpha_A<=1.25**, and require, after applying this gain, per-branch retained physical write RMS mismatch from the B self-projector <=25% for the shared `c>0` branch and <=40% for the private branch. B self-projector always uses gain 1.0. All other learned model layers remain intact. These are physical-dose comparisons, not promises of equivalent downstream Jacobians.

## Matched controls and allowed selection exposure

- Construct **exactly 2,048** candidate rank-four local projector perturbations around the A projector in NATIVE physical read coordinates using deterministic RNG seeded by root and a fixed angular choice from `{0.30,0.50,0.70,0.90}` radians per proposal. For each pass orthogonalize Gaussian rank-four complement vectors against the A top-eigenspace; candidate projector is `(cos(theta) E_A + sin(theta) F)(... )^T`. Source-only acceptance requires its retained physical write RMS on clean B discovery inputs within **15%** of the original A projector's RMS globally, within **20%** on the shared branch and **20%** on the private branch. Select the FIRST eight unique passing proposal indices with no evaluation outcome access. If <8, mark `BLOCKED_SHAMS`; never increase candidates after seeing roots.
- Use the **identical eight physical sham projectors**, with the identical `alpha_A`, for target-B held-out evaluation of A->B across both context branches. The rotated factor basis uses Q-transported versions of precisely these native physical projectors. Record the 2,048-proposal admission count and the eight selected indices, angles and discovery-only RMS errors. Matching on write magnitude does not match downstream sensitivities.
- A target-B self-projector (B->B) with gain 1.0 is the prespecified comparator. Also record clean-model B behavior, A->A retention, and descriptive B->A crossover; no causal winner selection, adaptive ranks, recurrent-pass interventions, or other controls are added after evaluation.

## Primary cross-task endpoints and independent-root analysis

On **new held-out B-marked** evaluation examples with independent external B labels, compute correct-label Bernoulli NLL for intact model, B->B keep-only, A->B keep-only, and all eight donor-sham->B keep-only. Stratify all values by the pre-existing context sign and retain whole-example metrics, per-pass KL(clean||arm), correct counts, accuracy, realized physical write displacement and exact per-root root-wise metrics.

For each root define:
- **Shared-branch excess transfer loss** `G_shared = NLL_B_shared(A->B) - NLL_B_shared(B->B)`. Small G_shared indicates the source subspace transfers a computation in the common label branch.
- **Private-branch excess loss** `G_private = NLL_B_private(A->B) - NLL_B_private(B->B)`.
- **Specificity contrast** `S = G_private - G_shared`. Positive S says transfer is relatively worse on the private branch.
- **Shared sham advantage** `H = median_8 NLL_B_shared(sham_i->B) - NLL_B_shared(A->B)`. Positive H distinguishes recovered source task subspace from local model-blind physical-dose nulls.

The **joint engineering positive-control gate** requires all EIGHT independent training roots pass clean-task, BPD parity, both projector eigengaps, physical-dose alignment, eight matched-sham, zero-head and native/rotated physical-map and output gates, plus **all**:
1. Upper Bonferroni three-comparison **98.333...% two-sided root-bootstrap interval** for `G_shared` <= +0.05 nats.
2. Lower familywise interval for specificity `S` **> +0.02 nats**.
3. Lower familywise interval for shared sham advantage `H` **> +0.02 nats**.

Use 4,096 deterministic percentile bootstrap resamples of all **eight model roots** at once (seed 909009 + endpoint index), with alpha=0.05/3 for each of three predeclared endpoints. Report rootwise effects and keep all failed gates. If no gate passes, publish `ENGINEERING_NULL_OR_INELIGIBLE`; CI remains green for a scientific negative. Evidence class is **development-only synthetic cross-task causal transfer**, regardless of result. No per-example significance claims.
