# AMM-09: bounded two-slot BPD strategy-memory transfer

**Preregistered 2026-11-18, before AMM09 experimental code or model training.** This is a new, source-locked prospective experiment. AMM08 (merged PR #102) supplied the development-only finding that the unrestricted three-component mask won nearly universally: memory-only selected the full mask on 99.50% of 32,768 cases, and it tied the pooled full-mask baseline at 14,125 successes. Although memory+local beat equal-budget local ridge by 3.24 percentage points, it failed the registered eight-point mechanism floor. This AMM09 intervention-budget restriction was selected using that visible AMM08 result. AMM08's development and every earlier AMM confirmation population are **selection-exposed or sealed and excluded** from AMM09 prospective inference.

## Research question and independent physical task

Question: Can a memory learned across separately trained recurrent models use **source-safe, per-case causal-response signatures** to choose better actions than a strong globally fixed two-slot intervention mask, when full rank-three injection is inadmissible?

The independent unit is **one separately trained 6D rank-three physical, three-pass weight-tied recurrent model and one separately trained BPD V/U decomposition**. Use AMM08's fixed training instrument and *fresh* SHA256 root streams `AMM09/<phase>/<index>`: source `(a,b,c)` uniform [-.8,.8], initial `h0=(0,0,0,a,b,c)`, readout `q(h)=h[0]`. Root family by parity: wren target order (a,b,c), basalt (c,a,b); external teacher targets `q(h1),q(h2),q(h3)` are defined before model training. Teacher `I[6,3],O[3,6]`, independent Adam 400 updates LR=.035 batch 96 on three pass target MSEs plus .0002 weight penalty. Independently initialize `V[6,3], U[3,6]`; train 240 Adam steps LR=.035 batch 96 using three teacher trajectory MSEs plus .5 physical weight reconstruction MSE. Canonicalize full VU with float64 rank-three SVD and report all three singular values/gaps. Retain every failed-fit or degenerate root in the intention-to-treat denominator.

Donor-recipient generation stays equivalent to AMM08 except for new AMM09 streams. Recipients have three source coordinates independently sampled Uniform[-.3,.3]. Independently perturb the source coordinates used for pass 1 (nuisance) by signed magnitude Uniform[.15,.70], and pass 2 and pass 3 (targets) by signed Uniform[.25,.45]. The donor's external pass-2 and pass-3 source values define the target, independently of fitted model and BPD factors. The agent is never given these external values or a full donor future readout.

## Registered physical action budget

The permitted component masks are **exactly six nonempty subsets of rank at most two** in immutable order:
`(0), (1), (2), (0,1), (0,2), (1,2)`.
The three-component mask `(0,1,2)` is excluded from all train, calibration, development, confirmation, choice, oracle and baseline action sets. *No counterfactual all-three result is computed by AMM09's intervention assay*; the full donor intermediate-state replacement remains a separately labeled **different-dose ceiling**.

Compute recipient and donor native first-pass BPD states `r1=F(h_rec)`, `d1=F(h_don)` and per-case physical dose `D=||d1-r1||_2`. For each allowed S, form canonical BPD write `z_S=((h_don-h_rec)@V[:,S])@U[S,:]`, zero its immediate readout coordinate, and normalize its L2 norm to D. A zero projection uses a fixed e1*D fallback, logging the event. Deliver **one** S-dependent write after pass 1. Continue the learned shared recurrent operator for both future passes; successful donor-specific repair requires *both* `|q(h2_patched)-y2_donor| <= .18` and `|q(h3_patched)-y3_donor| <= .18`. Retain all generated pairs and failures, including failed model fits, zero-dose and degenerate projections. Match the physical dose for isotropic dark-sham A and B; record sham zero patch, full donor state ceiling, current-readout drift and max dose discrepancy. Native `BPDModel/TiedComponentLinear PassMaskSchedule` three-pass parity and GL(3) shear/recanonicalization must pass on excluded roots.

## Equal information and frozen predictors

Each allowed candidate yields **18 source-safe features** identical in definition to AMM08: intercept, |S|/3, recipient and donor first-pass readout information, common physical dose, two candidate-specific delayed readout shifts and their magnitudes/squares/product, raw two future candidate readouts, patch/donor-write cosine, normalized minimum singular gap, first-pass nuisance dose fraction, and source family bit. The agent sees one common unpatched future continuation and the six allowed patched candidate continuations, at two future horizons, costing **14 unlabeled readout values per test case** (2+2×6). The same physical features and readout budget are available to all agents. The full donor future, source-defined target, clean calibration labels and scored test candidate success bits are audit-only.

Train on 64 independent model roots, **128 separate donor pairs/root** with all six allowed candidate success labels. Freeze a globally shared 18-feature ridge model (λ=10 on slopes, unpenalized intercept) of candidate success, with root-balanced training and **all 18 coefficients rounded to four decimal places**, plus the globally best *fixed permitted* mask by training hit count. Hash source, exact rootwise training candidate bits and quantized policy. Publish this immutable training lock in Git **before** generating development roots.

Each new DEVELOPMENT/CONFIRMATION root receives **16 calibration donor pairs**, all six candidate scores measured and each binary success label independently flipped with known p=.20 by root, action and case seeded noise. This supplies **96 identical noisy local labels** to every comparator. A local noisy-label value y has predeclared unbiased target `(y-.20)/.60`. Agents share the exact physical intervention budget, features and calibration reports; cross-model memory pays the disclosed additional amortized global-training corpus cost.

Frozen policies:
- **memory_only (primary)**: choose the highest predicted success from the frozen global 18-feature ridge, clipped to [0,1], among exactly six permitted masks. Deterministic tie break to lowest mask index. No local outcome labels enter this policy.
- **pooled (primary control)**: choose the single globally training-best admissible mask on every case, using the same training corpus and having access to the same permitted input features but ignoring case-dependent variation.
- **memory_plus_local (secondary)**: fit an 18-feature root-specific residual with ridge penalty 20 on *all* coefficients to de-noised calibration targets minus clipped memory priors. Add it to frozen global predictions and choose highest predicted admissible mask.
- **local_ridge (secondary strong control)**: fit the same 18 features and all 96 noisy labels from scratch using ridge penalty 2, unpenalized intercept, choose the highest predicted admissible mask.
- **local_count**: select the one permitted mask with highest noisy local success count, ties to lowest mask index.
- **random_mask**: independent per-case/root SHA256 bit selecting one of six admissible masks, `random_dark`, `random_dark_b`, zero `sham`, larger-dose `full_donor`: controls and descriptive ceilings.

Predeclare **four positive root-level comparisons**, with four-test Holm familywise α=.05:
1. **PRIMARY: memory_only minus pooled**. This measures case-dependent cross-root strategy memory beyond its own globally best fixed mask.
2. memory_plus_local minus pooled.
3. memory_plus_local minus local_ridge.
4. memory_plus_local minus memory_only (tests whether local updating improves the frozen prior).
Report all root signs and ties, 2,000 seeded paired root-cluster bootstrap 95% CIs and all test outcomes. The registered physical minimum for the primary is **+0.08 absolute success probability**, target **+0.16**. For a positive case-dependent cross-model memory claim, the primary lower 95% root-bootstrap bound must exceed the mechanistic floor and its Holm-adjusted sign p must be <.05. The two-slot restriction and the four-comparison family are frozen before AMM09 data.

## Evidence class and interpretation

AMM09 tests **synthetic independently trained 6D rank-three linear recurrent BPD causal-routing memory under a registered two-slot physical intervention budget**. The design establishes no direct results about nonlinear TRM/looped transformer mechanisms, natural neuron identifiability, real agent-to-agent memory, or deployed Buzz/Nostr networks. A positive claim requires demonstrated case-dependent improvement over the strongest comparable *fixed permitted* mask, a matched calibration policy comparison, all physical/fidelity gates, independent-root uncertainty and sealed confirmation.
