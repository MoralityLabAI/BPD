# BPD-NC-04: self-scored subspaces in an unconstrained recurrent model

**Prospective source-only registration, 18 November 2026 UTC.** Commit this document alone before implementing NC-04, initializing models, drawing data, or inspecting NC-04 outcomes. NC-01/02/03 are development context. All previous roots stay development-only.

## Hypothesis and evidence boundary

Test whether the rank-two recurrent projector instrument validated on NC-03's planted stage-shift survives a **freely trained dense** 20-dimensional nonlinear recurrent transition with four physical reuses of the same 20×20 weight. The previous experiment had a hard-coded stage/lane support constraint and equalized gains. NC-04 has **no planted sparse support, constrained stage-gain projection, or known subspace oracle**. The input/task definition is retained for direct comparison. This is a synthetic model with learned dynamics, **not an LLM or compact TRM**.

A mathematical control: in an **uncentered** gradient second moment, the external label sign cancels exactly because `(σg)(σg)^T = gg^T` for σ=±1. Accordingly, “model-generated score” means the fully independent model logit is used, without reading task labels in discovery; the gradient-covariance estimator is already mathematically sign-invariant. This change alone is not a distinct feature-discovery contribution. Positive-only activation×gradient community selections may vary with score sign and are a separate observational diagnostic.

## Fixed task, model and split

- Input: five independent N(0,1) variables, four candidate lanes and a context. External target: `(x0 if context>0 else x1)>0`, defined without reference to model state. Only the training loss and **held-out scoring** may call `external_labels`; the discovery function accepts no labels and must pass an oracle-blindness regression test.
- Independently initialized models on **engineering roots 400–407**. Each trains from 2048 input cases (split 1), Adam at `lr=.005`, batch 128, **384 updates**, binary logistic loss `softplus(-2*y*final_logit)`. There is no ground-truth hidden trajectory, architecture oracle or prior stage-shift matrix.
- Architecture: `encode=Linear(5,20)`, `pre=Linear(20,20)`, `mix=Linear(20,20,bias=False)`, `head=Linear(20,1)`. All initialize from the root seed with standard PyTorch initialization and all trainable entries are free to update. At each of **four shared passes**: `a_t=tanh(pre(h_t))`, `w_t=mix(a_t)`, `h_(t+1)=tanh(.60*h_t + .65*w_t)`, with `h_0=tanh(encode(x))`. A readout is recorded from the full hidden state after each pass. No input injection after h0.
- Use exactly **1024 separate discovery examples** (split 2) and **1024 held-out evaluation examples** (split 3) per root. Root-dependent deterministic Gaussian streams are disjoint and separated from training. One training root, not a prompt or pass, is the independent unit. Report context-wise heldout task accuracy; >=85% for each context is the declared task gate, and physical `mix` density (fraction of entries with absolute weight >=1e-4) must be >=90%. Gate failures stay in receipts.
- Engineering-only CI smoke uses root 400, 256 discovery and 256 evaluation, 384 updates; only 256 sham proposals. Confirmation roots are never sampled by this implementation.

## Discovery and factor bases

- The only causal target is **the physical shared `mix` linear**. Other learned `pre`, `encode` and `head` remain intact; keep-only sufficiency means sufficiency *at that write site*, not a whole-model circuit.
- Frozen model readout score `s(x)=final_logit(x)`. Per-sample model-generated sign `σ(x)=+1 if s>=0 else -1` is detached. Discover using `σ(x)*s(x)` solely to label-align self-confidence. No external target labels enter discovery. Intermediate write gradients are `∂(σs)/∂w_t`. Compute `z_t=a_tV`, `∂s/∂z_t=(∂s/∂w_t)U^T`, and `C_t = mean(∂s/∂z_t)^T(∂s/∂z_t)` in float64.
- **One fixed projector rank 2.** Eigengap condition at every pass: `lambda_2 > 1e-12` and `lambda_2/max(lambda_3,1e-12) >= 1.10`. This is a revised, **prospective** threshold for a dense model, independent of NC-04 results; NC-03's ≥100 planted spectral gate must not be silently inherited. Report all passwise eigenvalues and ratios. If any pass fails, report `UNIDENTIFIABLE` with complete diagnostics.
- Bases: **native** `V=I,U=W^T`, **rotated** `V=Q,U=Q^T W^T` with root-seeded deterministic Haar orthogonal Q. Both must reconstruct `W` at residual ratio <=1e-4 and have full-ones BPD parity at all four logits (max abs <=5e-5 and double-precision KL <=1e-7). No learned BPD or SAE features are implied.
- Secondary observational Goodfire-style coordinate-graph diagnostic on exactly the same discovery gradients: per-sample top-eight positive `z*grad` entries, co-occurrence >=12, phi >=.15, mutual-top-four graph, components 2–12, with cross-pass counts and 16 independent per-pass row-shuffle nulls. This diagnostic **has no causal winner selection** and is excluded from the primary family.

## Causal interventions and paired physical shams

- For eligible rank-two projectors, apply exactly the NC-03 native closed-loop physical `BPDModel.intervene("mix", all_factors, mode="override_read", read_override=V@P_t, scale=0)` procedure to preserve the discovered pass-specific subspace, and the complementary projector to ablate it. Rerun the 4-pass student recurrently in both cases.
- On discovery clean states compute retained physical write RMS from factor-activation second moment and the actual `U U^T` Gram. Lock **2048 oracle-blind candidate Haar projectors**, each rank 2 inside the leading four eigenvectors of discovery activation covariance. Candidates are generated in **native physical coordinates**, then transported into the rotated basis. Select the eight unique closest candidates with **retained RMS within 15% of discovered projector dose**, with no held-out outcomes or labels. If fewer than eight, mark the root `BLOCKED_SHAMS`; never search held-out outcomes for eligible shams.
- Primary root-level causal contrast, **external behavioral endpoint**: `median_8(NLL_true_label(sham_keep)) - NLL_true_label(discovered_keep)` in **nats**. Also report `NLL(discovered_keep) - NLL(clean)`, KL(clean||keep) and KL(clean||ablate) for all four passes, clean and modified task accuracy, per-pass signed effects and actual closed-loop write RMS displacement.
- The same eight physical shams must be assessed in both factor bases. Compare physical operator `V P U` across bases within relative Frobenius error <=1e-4 and kept-model logits within 5e-5 on heldout. All parity and dose failures block causal interpretation.
- Negative controls: set trained `head.weight` and `head.bias` to zero on a fresh model state while running discovery: every intermediate score gradient should be zero, and the projector should report `UNIDENTIFIABLE`. Check the exact sign-cancellation identity for the uncentered second moment. Report the clean-model 4-pass accuracy trajectory as evidence that recurrent passes alter behavior.

## Independent-root resolution and rule for outcome reporting

- Eight engineering roots are a development diagnostic, never a confirmation population. The planned **one** primary discovered projector and eight dose-matched shams/root yield **one paired effect per root**. Bootstrap entire roots, not cases, intervention angles or passes, with 4096 fixed-seed bootstrap resamples.
- Scientific minimum effect `delta_mech = +0.02 nats` true-label external NLL advantage against matched shams. The gate for an *engineering positive-control signal* is all eight roots meeting parity, model density, two-context accuracy, eigengap, zero-head and dose matching; a root-mean effect bootstrap 95% lower bound **>0.02 nats**; **mean** kept-minus-clean NLL <=0.05 nats; and native/rotated output/operator agreement as above. Otherwise preserve `NOT_RESOLVED_OR_FAILED` as a successful CI scientific outcome. Do not inspect extra directions/ranks or alter thresholds after seeing results.
- Matching on physical write RMS controls energy, but not Jacobian effect, sensitivity, or task importance. Report sham-variation distribution and realized write displacements. The 95th-percentile sham envelope at 95% confidence needs >=59 independent sham roots; **eight does not suffice**. Full EvalMath mechanistic-power preflight is required before any later confirmation.
- All eight complete root receipts, algorithm source SHA256, protocol SHA256, training and evaluation budgets, all sham scores and exclusions must be retained. Keep sealed ARG-03-N and AMM-03 cohorts untouched. Never download pretrained weights in this experiment.

## Verdict boundaries

Possible finding: **rank-two output-gradient projectors, rather than planted coordinate paths, can causally preserve behavior in one new family of dense trained recurrent models**, while respecting orthogonal factor changes. Claims of generic neuron communities, learned SAEs, hidden proof state, and natural LLM mechanisms require additional experiments and new independently registered populations.
