# SCCG-01
Selective causal controllability in weight-tied networks. See [theory](THEORY.md)
and [prospective design](PROTOCOL.md). Stacked on INK-BPD-06 (#161).
The NumPy reference solves a scalar local target with physical L2 and
collateral budgets. A native reader fixture adapter quotients redundant
physical writes; source-parameter intervention and full neural continuation
are outside this instrument. The tests include a SciPy independent optimizer
and exact rational witnesses. To run from repo root:
    python -m mechinterp.bpd.experiments.sccg01.exact_witnesses
    python -m unittest discover -s mechinterp/bpd/experiments/sccg01 -p 'test_*.py' -v

Install numpy and scipy. The workflow pins versions. Engineering only.
No trained checkpoint, task outcomes, new independent model roots,
confirmation data, Lean build, or hardware claim. The theory is a
proposed BPD synthesis of classical methods; novelty remains open.
