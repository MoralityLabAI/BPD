## Goal and independent unit

Test whether **replicate-disagreement evidence**, collected without observing clean calibration truth, lets an agent choose per-case BPD interventions more accurately than an equally budgeted agent that assumes the population-average judge reliability. The independent unit is one independently Adam-trained 4D rank-two weight-tied recurrent physical model plus separately trained rank-two BPD decomposition and its root-local judge channel. No case, model checkpoint, or random stream is reused from AMM-01 through AMM-06.

The generator and external task remain fixed: `h0=(0,0,a,b)` with family wren `q(h1)=a,q(h2)=b` and basalt `q(h1)=b,q(h2)=a`. Train a physical factorized transition for 200 Adam updates at LR=.035, batch 96 and .0002 weight penalty, then fit V,U for 140 Adam updates at LR=.035 to independent teacher trajectories plus .5 matrix MSE. Canonicalize VU by double-precision SVD, logging its singular gap and separate source-heldout teacher/factor behavioral MSE and relative operator reconstruction error. Both physical factors and both BPD factors must update. Models whose fit is poor **remain in the all-root denominator**. Before running development, freeze a diagnostic fidelity flag using independent source validation: `teacher_behavioral_mse<=1e-4`, `factor_behavioral_mse<=.10`, `weight_reconstruction_relative<=.50`, `singular_gap>.01`. A minimum 56/64 high-fidelity development roots is an additional scientific admission veto, not an exclusion rule.

Every donor pair changes the independent second-pass target source coordinate by a signed 0.30..0.45 and the nuisance coordinate by signed 0.15..0.80. An agent chooses exactly **one** of two SVD-canonical component writes per pair, projected to the immediate current-readout kernel and matched to a common actual within-pair L2 dose. Continue the learned weight-tied operator; score success by `|q(h2_patched)-donor_external_y2|<=.18`. Count all pairs, including zero-dose, failed-fit or degenerate patches. Equal-dose isotropic random-dark, sham, and larger-dose full-donor controls are retained.

## Independent replicate-feedback instrument

Use a fresh AMM07 SHA256 stream, with `engineering=8`, `training=64`, `development=64`, `confirmation=128`. Family is index parity; hidden judge reliability is `(index//2)%2`, making every phase balanced across family×judge regimes. Each root-local judge flips each underlying component success bit independently with probability `q=0.10` (low noise) or `q=0.45` (high noise). The true quality label and clean target are audit-only.

Each development/confirmation model receives exactly **16 source-disjoint calibration donor pairs**. Both candidate interventions are observed and each candidate's binary success is reported **twice**, with independently generated label flips. This costs **16 pairs × 2 candidate actions × 2 judge calls = 64 noisy local labels**, shared identically by every competing agent. Each agent also receives the same eleven-dimensional SVD-canonical candidate geometry and **three unlabeled continuation probes per donor case** (one unpatched and two candidate continuations). Policies never see donor_future, donor_external_y2, clean calibration truth, hidden judge mode, or test success bits.

Calibration pairs 0–7 (16 candidate outcome pairs) are reserved for **quality estimation**. On each duplicated response pair, define disagreement `D=1[r1 != r2]`. Because the duplicate flips are independent conditional on a latent clean label, `P(D=1|q)=2q(1-q)`, which is .18 for q=.10 and .495 for q=.45. With 16 first-half candidate pairs and equal prior root quality, compute the exact log posterior odds and `posterior_low`. A classification `posterior_low>=.5` is recorded but cannot be fed the true regime. A pre-registered diagnostic prerequisite for scientific confirmation is >=80% correct regime classifications over all 64 independent development roots. This prerequisite is **veto-only**.

## Cross-model memory and Bayesian update policies

Freeze AMM-06's *functional* eleven-dimensional candidate causal-response signature and common three-probe budget, with **new AMM07 roots**. Train one ridge linear regression (λ=10, free intercept) from both component behavioral successes on **64 independently trained TRAIN roots × 128 donor cases/root**, freeze all 11 coefficients and pooled best component, and commit a source-hashed receipt before generating development roots.

For each root's remaining 8 calibration pairs (16 candidate underlying success bits, each reported twice), calculate a soft posterior `E[t|r1,r2,p_memory,w]` of the unobserved clean target. For each q∈{.10,.45}, the likelihood of two reports conditional on clean t=1 is `(1-q)^k q^(2-k)` and on t=0 is `q^k (1-q)^(2-k)`, where k is the number of reported ones. Marginalize these likelihoods across q with weights `w`, then update the prior success probability `p_memory` by Bayes' rule. Clamp p_memory to [1e-6,1-1e-6]. Fit an 11-feature ridge residual (λ=20, **penalized intercept**) to the soft posterior minus p_memory on the **last eight** calibration pairs. Choose the component maximizing clipped `p_memory+predicted_residual` on each independent heldout test case. No test labels or audit-only clean labels enter the fitter.

Frozen primary agent **quality_aware** uses `w=(posterior_low,1-posterior_low)` from the *first eight* calibration pairs. Equal-local-budget primary control **quality_blind** uses fixed mixture `w=(.5,.5)` and the **same last eight** fit pairs. Secondary comparison `quality_aware - blind_all` uses an otherwise identical fixed-mixture soft posterior/ridge fit on **all 16** calibration pairs (a stronger, fully labeled-budget comparator). Third registered comparison is `quality_aware - memory_only`. Additional descriptive arms: `local_ridge` using all 16 calibration pairs, constant p=.5 prior and λ=2; `pooled`, `random_component`, `random_dark`, `random_dark_b`, `sham`, and `full_donor`. Every arm receives the same calibration/probe information budget; alternative use of the shared feedback is explicitly disclosed. The memory arms pay the additional amortized global 64-root training corpus.

## Fixed sample, inference and stopping gates

Primary and repeatability tests each contain **1024 separately generated donor pairs per new model root**, selected independently of its calibration pairs. This raises within-root measurement resolution while retaining one model root as one independent unit. Development comprises **64 independent model roots** and confirmation reserves **128 untouched independent roots**. Even an engineering test with a missing/invalid preflight is forbidden to enter confirmation generation. Confirmation also requires a separately committed human-approved release manifest binding exact source, training policy, planner receipt, quality-classification and fidelity gates.

Primary contrast = root-mean `quality_aware - quality_blind` actual donor success probability. Two registered secondaries: `quality_aware - blind_all` and `quality_aware - memory_only`. Use root-level one-sided exact sign tests, Holm multiplicity across **three** declared comparisons (familywise alpha=.05), and 2000 seeded paired root-bootstrap 95% percentile intervals. Scientific minimum effect **+.08**, target effect **+.15**, single-root outcome resolution `1/1024`. Preserve failed roots and every zero-effect comparison.

Sham calibration uses the **same frozen quality_blind policy** on two independently drawn 1024-case cohorts from each of 64 development roots, with exactly matched physical patch dose per case. Compute the absolute success-rate difference per model root; use the 64-value sample maximum as a nonparametric 95th-population-quantile upper tolerance at >=95% confidence. EvalMath's corrected mechanistic-resolution planner, pinned at `MoralityLabAI/EvalMath@6d9c28dbe8e4c42b3fba76ae7adb84aed9f0921a`, receives the paired primary effects, independent sham values, target and the predeclared 128-root confirmation budget. A `REDESIGN_OR_PILOT_ONLY` verdict is an immediate confirmation block.

Additional vetoes even if READY: >=52/64 correctly classified hidden quality roots, >=56/64 high-fidelity factor roots, and an **audit-only** per-case test-label-oracle accuracy headroom of at least 8 percentage points above `quality_blind`. These conditions may stop an under-instrumented experiment; they **cannot** be used to select model weights, tuning constants or a new confirmation hypothesis. Confirmatory success additionally requires Holm-adjusted primary p<.05, its paired-root bootstrap lower bound above max(.08, 95/95 sham floor, 1/1024), no physical-dose or native-parity failure, and positive rootwise directional gain over blind_all.
