# BPD-SF05B Stage 2-B: source-conditioned visible-readout closure and public invariance

**Prospective development-only four-arm teacher ablation, November 18, 2026.** Parent: [Stage 2-B issue #62](https://github.com/MoralityLabAI/BPD/issues/62), [Stage 2-A model-admission PR #61](https://github.com/MoralityLabAI/BPD/pull/61). No newly reserved scientific roots are involved. Source, training arms, evaluation outputs and controlled seeds are fixed **before any new Stage 2-B model-heldout result is generated**.

## Why new model training is justified

On excluded trained roots 901 and 902, the frozen Stage 2-A source-aware generator increased model-eligible source swaps to **43/512 and 20/512** under authorized unconditional queries, or **42/512 and 29/512** in a ≥0.30 exact-label-gap source stratum. The high-contrast target gap is large, but the *model's current prequery scalar readout* changes under the private source-tag switch and often fails the ≤0.05 co-closure gate. Separate public-role U cohorts (512 each, without clean-model selection) show last-tag source-conditioned public-output differences 0.03981/0.06966 despite an exact public target unaffected by the source tag. The Stage 1 nonprivileged policy only lowers edit-induced public output deviation to 0.03409/0.06717, failing the proposed ≤0.02 reference.

A stronger source-private mechanism should enforce co-closure **while retaining correctly routed authorized output**. Stage 2-B tests whether two explicit *training-only* regularizers improve the structural behavior of the same recurrent teacher. The new effect belongs to the teacher's **training objective**; any BPD physical factor recovery is a reconstruction benchmark and must not be called a canonical secret circuit.

## Shared physical model, training and four frozen arms

Use the unchanged 32D hidden, 64D tanh feature and 11D input Stage 1 shared physical transition \(F_\theta(h,x)=h+\tanh(hA+xB+b)C\). All valid 2–4-write histories for **training** are generated by the unchanged Stage 0 \`F_train\` generator. The base Stage 1 teacher uses 2600 Adam updates, batch 128, LR 0.012, intermediate visible scalar penalty 0.15, final supervised loss coefficient 4, fixed weight-decay objective 1e-4, gradient clip 5 and seed-specific deterministic initialization.

For the additional regularizers, draw an **independent training-only donor** for each source history by changing only the last valid write's source tag, preserving all scalar payloads, earlier events and final query. This donor generator uses Stage 0 \`change_last_source\` with train-step seed \`seed*290000+880000+update\`. The original final supervised loss, samples, optimizer and schedule are unmodified.

Write \(h_r,h_d\) for the prequery states after the last valid source write, and \(x_U\) for the role-U public query constructed from the **same public scalar**. Define:

\[
L_{\mathrm{current}}=\mathbb E\,\big(q(h_r)-q(h_d)\big)^2,\qquad
L_{\mathrm{public}}=\mathbb E\,\big(q(F_\theta(h_r,x_U))-q(F_\theta(h_d,x_U))\big)^2.
\]

Compare the following four **registered arms**, using the same root seeds 901/902, identical original base objective and identical F_train batches:

| Arm | Current co-closure coefficient \(\lambda_c\) | Public source-invariance coefficient \(\lambda_U\) |
|---|---:|---:|
| \`baseline\` | 0 | 0 |
| \`current_only\` | 1.0 | 0 |
| \`public_only\` | 0 | 1.0 |
| \`joint\` | 1.0 | 1.0 |

For the baseline call the exact **unmodified Stage 1** \`train_teacher\`. The other arms add \(1.0L_{\rm current}\), \(1.0L_{\rm public}\), or both to its original loss. New losses are **training-only**, calculated on F_train with the same frozen physical teacher; no heldout event family, new scientific root or oracle-refined test response participates in training. The loss weights were chosen as simple unit-strength engineering probes, without inspecting Stage 2-B heldout teacher outcomes.

## BPD and nonprivileged policy transfer

After each trained teacher is frozen, fit the unchanged full-rank 32-component Stage 1 physical BPD V/U model for 450 updates and train the same bounded nonprivileged correction policy for 240 updates on F_train privileged Newton oracle labels. Keep these factor/policy training schedules, initialization seeds, output-SVD rank 24 and inference-time prohibition against true public future outputs/gradients unchanged across all four arms. A pure GL(32) factor-gauge shear must preserve the physical write. Report native BPDModel/TiedComponentLinear parity using the separately tested baseline implementation, and distinguish physical reconstruction from sparse-gate discovery.

## Reused, predeclared independent heldout cohorts

For **each arm/root pair**, evaluate exactly the same three source-conditioned \`F_heldout\` cohorts and seed offsets from Stage 2-A:

- \`authorized_unconditional\`: 512 source-tag-only donor pairs with query drawn from the last old/new source;
- \`authorized_high_contrast\`: 512 pairs retained as the first qualifying among 2048 generator candidates under the exact label-gap ≥0.30;
- \`public_U\`: independently seeded 512 public-role target-unchanged pairs; **all** examples enter public-output metrics.

Use the original Stage 2-A sequential model eligibility gate unchanged: both clean recipient/donor target errors ≤0.10, their prequery visible scalar difference ≤0.05, and their clean final outputs differ ≥0.20. Report all independent and sequential counts. Across arms, the *same* generation seeds and source labels are held fixed to permit **within-root paired comparison**.

For each authorized cohort report raw and bounded-policy corrected full/rank-24 physical BPD donor recovery on all eligible cases, plus exact hidden donor-state, teacher-C, zero edit, privileged Newton and 16 independent same-policy corrected random and pre-correction signed authorized-gradient matched shams. Report physical rank gap and gauge parity. For the public U cohort report clean model public-label MAE, clean source-tag-only output difference, raw versus learned-corrected public deviation and privileged oracle ceiling across all 512 examples.

## Predeclared engineering and descriptive decisions

Every arm/root must produce finite model/task metrics, correct-source labels, full physical factor MSE, bounded policy corrections, current-readout preservation and unfiltered public-cohort denominators. A failed arm/root must remain in the result. As a development target (not a confirmatory statistical test), look for all the following per excluded root:

- Teacher heldout overall MAE ≤0.12 and public U target MAE ≤0.05;
- both clean target-correct and current readout-close donor count ≥100/512 in either authorized cohort;
- clean source-tag-only public-U output difference ≤0.02, and learned corrected physical BPD public-output mean Δ ≤0.02 across all 512 independent U cases;
- maintain exact physical full-block donor retrieval ≥90% on clean eligible authorized pairs.

These thresholds are **engineering benchmarks only** on the already used roots. If no arm meets them, preserve that failure and identify which clean teacher or public output mechanism requires rethinking. A source-dependent public output can still be present even if the policy edit is small.
