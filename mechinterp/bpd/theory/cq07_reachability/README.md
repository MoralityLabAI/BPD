# BPD-CQ-07: reachable-state feasibility, a negative engineering result

This folder implements the [CQ-07 issue #47](https://github.com/MoralityLabAI/BPD/issues/47) feasibility audit, following [CQ-06](../cq06_nonlinear_feedback/RESULTS.md). It reuses the exact CQ-06 learned tanh recurrence and source generator, retraining physical and BPD factors on **eight exposed development roots only**. The original CQ-06 test and calibration receipts are unchanged.

[Protocol and selection exposure](PROTOCOL.md) · [Conditional mathematical no-go](THEORY.md) · [Eight-root results](RESULTS.md) · [EvalMath preflight](PREFLIGHT.md)

CQ-07 distinguishes three state classes: mathematically reachable states from legal first cues, arbitrary coordinatewise in-range tanh outputs from constrained BPD preactivation changes, and projected/rescaled additive vectors that can even leave the tanh box. The legal first-cue span and chosen rank-two BPD write span have trivial intersection on all eight development models, which blocks an **exactly reachable nonzero rank-two preactivation patch** in this architecture.

A separate reservoir null consists only of actual clean first states generated by the trained recurrence. It matches first parity, current-head logit within 0.30 and physical state displacement within ±0.15. All generated donor pairs remain in the denominator and unsuccessful solver/matcher calls score zero for both arms. The exploratory result is a matched-control tie, with low joint feasibility. The strict EvalMath preflight blocks confirmation; **no 59-root CQ-07 sham or 26-root CQ-07 confirmation was run**.

The source-locked check will use the write-once archived eight-root development receipt. Native execution uses actual `BPDModel/TiedComponentLinear` at the second pass via `PassMaskSchedule` and checks the source-locked per-root counts. This work is deliberately an *engineering feasibility negative*, rather than a new positive causal claim about natural model fibres.
