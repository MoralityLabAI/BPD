# BPD-CQ-07: reachability feasibility and matched clean-source audit

**Status:** development-only geometric feasibility audit, authored after inspecting the excluded-root engineering data. This experiment is **not** a prospectively blinded confirmation and has no CQ-07 sham-calibration or confirmation result. CQ-06's 59-root and 26-root receipts, geometry audit, and claims remain intact. The CQ-07 research question and design goal were set in [BPD issue #47](https://github.com/MoralityLabAI/BPD/issues/47) before this audit.

## Core mathematical claim and observable witness

Keep the CQ-06 nonlinear weight-tied model: hidden dimension D=12, initial h0=0, valid first cue `u0=(x,y,0,-1)Q_seed`, tanh shared transition `s1=tanh([0,u0] W+b)`, learned W=VU (rank 4), and independent delayed sign label `L2=sgn(x z)`. The donor flips both x and y, preserving `L1=sgn(x y)`, reversing L2 at the same z. Reuse only CQ-06's **excluded development seeds** `(997,1009,1013,1021,1033,1039,1049,1051)` and separately retrain the physical and BPD factors at those seeds. These roots are already exposed to model-development choices and therefore are exploratory.

The legal first-pass preactivation is `p(x,y)=b-Q[3,:]W_in + x (Q[0,:]W_in)+ y (Q[1,:]W_in) = p0 + (x,y) A`, where A has two rows in R^12. The selected top-two canonicalized BPD component writes span rows B=U[0:2,:] in R^12. If `rank([A; B])=4`, then `rowspan(A)∩rowspan(B)={0}` and **no nonzero selected two-component preactivation intervention can be exactly equal to the preactivation of another legal first-cue state**, even allowing arbitrary real x,y. Mathematical tanh is injective coordinatewise, so this preactivation obstruction carries to exact state equality. In finite-precision code the numerical certificate reports all four singular values and the smallest one; rank tolerance 1e-6. The source cue magnitude restriction `.65<=|x|,|y|<=1.20` can only reduce the legal set. A tanh-clipped vector inside [-1,1]^12 is not automatically on this lower-dimensional reachable set.

## Development-only in-range optimization, fixed controls

For each seed, generate **128 donor/recipient pairs** via CQ-06's untouched `donor_inputs(seed, 128)`. The first-pass state is the full reconstructed BPD recurrence. Two selected BPD component activations are computed from the donor-minus-recipient **first-cue** read difference. Form `s_patch=tanh(p_rec + (alpha⊙((u_d-u_r) V_01)) U_01)`, with two scalar amplitudes alpha initialized to 1 and clamped to [-1.5,1.5]. Optimize only alpha for 200 Adam updates at LR .045 to minimize mean `[10((q(s_patch)-q(s_rec))/.30)^2 + 10((||s_patch-s_rec||-||s_d-s_rec||)/.15)^2 + .015||alpha-1||²]`. No donor label or future outcome appears in this optimization. The constrained solution passes feasibility iff `|q(s_patch)-q(s_rec)|<=.30` and `|physical patch dose - clean full-donor dose|<=.15`. Count all 128 generated pairs, including optimization failures. The constraint uses current-head **logit displacement**, not merely equality of binary first labels.

For each source world, generate two independent, **actual legal first-visit source reservoirs**, each of size 4,096, seeded at offsets +951000 and +953000. Feed each source's first cue through the already trained BPD physical transition. Choose a clean state using only matching first parity, `|head_alt-head_rec|<=.30`, and `| ||s_alt-s_rec|| - ||s_patch-s_rec|| |<=.15`. Break candidate ties by minimizing normalized head plus dose error, then source index. Never project, rescale, or interpolate the selected clean state. Leave every unmatched pair in the denominator. Record the chosen state's true x sign *after* matching for diagnostic use only; the matcher cannot see donor target, donor x sign, or second cue.

The primary exploratory *joint-feasibility comparison* scores a pair only if the BPD optimization **and** the first clean-source match pass. On infeasible pairs both arm scores are zero, preserving all 128 per-root denominators without rewarding unequal feasibility. Recompute the trained CQ-06 second-pass feedback mask from the patched state plus recipient z and execute actual native `BPDModel/TiedComponentLinear` at pass index one. Record delayed donor-target hits in both interventions, and the clean donor full-state ceiling, sham, and raw two-component tanh patch. Compare a second independently matched reservoir in a common-joint-feasibility subset as a sham-direction check. Individual-pair binary successes and feasibility flags are retained.

## Hard geometry controls and interpretation limits

Engineering hard gates: `rank([A;B])` verified with singular-value witness, zero tanh-box violations, exact clean-reservoir source provenance, parity and actual state-distance tolerance for all accepted clean matches, all 128 donor pairs counted, native and independent second-pass parity <=1e-5. Exact reachability for the constrained BPD patch is assessed by the **preactivation residual** to the legal input affine span; tolerance 1e-4, nonzero dose >1e-6. Report the entire residual distribution and count. The two root-level causal arms are measured only on this exposed synthetic-development family.

The clean reservoir is a finite Monte Carlo subset of the legal input manifold. A missing candidate means only that the prespecified finite bank failed to match, not that no natural match exists in the continuous manifold. Physical doses of accepted clean controls are matched to a **registered coarse band ±0.15**, rather than exact equality. This is a feasibility audit and cannot establish a new confirmation-grade causal quotient. Causal efficacy under strict reachability may require clean-state intervention with factor-specific **mediation** measured at the subsequent pass instead of a nonzero selected rank-two additive write.

## EvalMath stop condition

The independent unit is a fully retrained rotation/model/factor/policy root, eight exploratory roots. The minimum useful causal gain is 15 percentage points, observed development effect estimated from BPD versus accepted clean-source controls. Run the EvalMath mechanistic-resolution preflight using **only these development roots** and two independent reservoir sham arms, planning 26 hypothetical fresh confirmation roots with no seal currently registered.
