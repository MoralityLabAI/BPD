## Mechanistic question and nontrivial information barrier

Model input arrives in two visits. At visit one, a learned recurrent model sees signed continuous magnitudes of x,y in [-1.20,-.65] ∪ [.65,1.20]. It must predict the first label L1=sgn(xy). Only at visit two does the model receive a fresh independent z in the same support; it must predict L2=sgn(xz). All inputs are rotated by a separate orthogonal 4x4 code per model/world root. The root-specific rotation and the independently trained physical weights are new in each world. An exact algebraic solver reaches 100% with access to both cues. In a deliberately paired z/+ and z/- heldout task cohort, any deterministic prediction of L2 based solely on visit-one information has at most 50% accuracy on that cohort. The first readout L1 cannot determine x alone because x,y are balanced, and donor pairs flip both x,y while keeping L1 fixed and reversing L2 at a fixed recipient z. This is the delayed dark-variable test.

The teacher is one shared nonlinear weight-tied state transition with 12-dimensional state and 4-dimensional per-visit cue: s_{t+1}=tanh(([s_t,u_t]A)B+b), with A[16,4], B[4,12], b[12] and shared trained linear scalar readout q(s)=Cs. Train 850 Adam updates at LR=.018, batch=128, minimizing softplus(-L1 q(s1)) + softplus(-L2 q(s2)), regularizer 0.0004 mean squared factors. Teacher initialization seed offset +1000; training draws seed offset +20000+update. The first cue has x,y,0,-1 before rotation; the second has 0,0,z,+1. The exact generator supplies all labels independent of training and decomposition.

Freeze the learned teacher. Fit a second BPD V[16,4],U[4,12] factorization from a new stream (+240000+step) over 600 Adam steps, LR .05, comparing both teacher states and complete physical matrix (weight 0.5); this is a separate model-fitting phase. Decomposition initialization offset +87000. Canonicalize (V,U) by float64 SVD of its full product VU before training a policy or selecting intervention components, retaining rank four and sorting descending singular values. Record reconstruction error, teacher/student classification and singular gaps. A native BPDModel/TiedComponentLinear backend must execute the same V,U and masks using PassMaskSchedule with delta_mask=0; test output parity with an independent Torch implementation at <=1e-5. The nonlinearity and bias execute outside the masked physical wrapper.

## Adaptive mask and controls

Always execute four components on the first visit. On the second visit, learn four input-adaptive hard mask bits from (the actually reached s1, the fresh u1); the controller never sees L2 or x,y raw at test. Train it on 4096 fresh development examples (offset +610000). On the training stream only, enumerate all 16 pass-two component masks with the first pass full, select the smallest cardinality retaining the fully active model's second readout within .7 logit units **and** second-state RMS distance <=1.15; tied choices minimize logit drift, then fixed binary pattern order. If every candidate fails, choose the smallest combined drift and retain the failure. This oracle observes the *full model outputs*, never the true independent task labels, avoiding label-based answer coding. Train 4-bit BCE imitation with a tanh MLP of widths 48/48, Adam LR .009, 500 updates, batch 256. At test hard logits >=0 ->1. Gate weight initialization offset +50200, minibatch RNG +610002. A standalone input-only planner using initial cue u0 with equal training updates and the same imitation labels is the central feedback control; calibrate its global threshold on a separate stream to match the adaptive gate's expected slots, with threshold chosen only by slot-cardinality alignment.

Calibration (+620000; 1024 draws/root) is disjoint from training, heldout and donor streams. Select the best two-support randomized input-blind mixture of the 16 constant pass-two masks by calibration binary task accuracy under expected active-slot budget <= the feedback gate's calibration budget. Score a random equal-per-case-cardinality pass-two mask, the exact algebraic solver, frozen-initial-input planner, and full 8-slot native execution. Report actual per-arm slot budgets. Include one-pass information bound and exact paired-z ceiling. The engineering gate requires full model behavior, parity, per-case dose and a nonzero calibration benchmark. No pretest parameter selection is allowed after the source is frozen.

## Donor estimand: all 128 pairs per independent root

Draw 128 paired donor/recipient examples per root (offset +811000), with continuous magnitudes and signs. Donor flips *both* first-visit x,y signs while retaining magnitudes and recipient z. The two first-step behavioral labels are identical; second behavioral labels are opposites by construction. The recipient's first-step four-component state s1_r and donor's full state s1_d are read from separate clean runs. Select exactly the two **largest singular components 0 and 1** from the canonical rank-four BPD decomposition, without choosing on intervention outcomes. Compute their donor-minus-recipient **first-pass component preactivation write** δ_pre = ((((0,u0_d)-(0,u0_r))V) ⊙ [1,1,0,0])U, and its nonlinear state displacement δ = tanh(pre_r+δ_pre) - s1_r. This is a rank-2 component *partial* patch, not a full-state donor replacement.

Project δ to the current head kernel ker(C): δ_dark=δ−(δ·C/||C||²)C, then scale to exactly ||δ|| in state-space Euclidean norm per pair. Compare to two independently drawn Gaussian directions in ker(C), each scaled to that same raw state dose, **and two stronger matched-manifold nulls**. For each manifold null, draw an unrelated clean first-step source from a separate root-specific RNG stream (+814000 / +815000), fix its first-step parity to match the recipient by flipping y if necessary, take its clean intermediate-state difference from the recipient, project to ker(C), and scale to the same raw state dose. The pre-registered primary null is **matched-manifold #1**, because arbitrary Gaussian directions can leave the learned state manifold. Gaussian controls remain descriptive. Include sham, current-visible-only norm-matched direction, raw unprojected partial patch, and full donor intermediate-state replacement (larger-budget ceiling). Record whether patched states leave the tanh range [-1,1] and the exact equal-dose error for every arm. Patch the recipient *between* visits; always keep its second cue u1 and independently known target L2_d. Continue through the true learned nonlinear BPD transition under (a) recomputed mask from reached patched state (feedback) and (b) the frozen clean-recipient mask. Score whether sign(q(s2)) equals L2_d for **every generated pair**, regardless of clean function, same mask, eligibility or zero dose. Preserve case-level binary rows in receipts. Report first-readout perturbations, state patch norm error, mask-switch counts and all source strata. The main primary difference per root is feedback rank-two dark BPD minus feedback same-dose **matched-manifold dark #1**. The second registered comparison is feedback dark BPD minus frozen-mask dark BPD.

## Independent worlds, sham tolerance and prospective decision

Independent root: one newly rotated input world, freshly initialized/trainable physical recurrent model, separately fitted rank-four BPD factors and newly trained controller. Model seeds are unique per partition:
- Excluded development roots: 997,1009,1013,1021,1033,1039,1049,1051 (8 roots); these may determine pilot effect SD for the EvalMath preflight.
- Independent sham-calibration roots: 4001+2i for i=0..58 (59 roots), computed BEFORE confirmation and used to form the null maximum of |success(matched-manifold dark #1)−success(matched-manifold dark #2)| / 128 on the same donor pairs. All 59 roots also contribute development-only BPD-vs-manifold paired effects to estimate power; confirmation roots are excluded. This is a physically dose-matched random-direction exchangeability null, not a source-aware learned-component null.
- Sealed confirmation roots, kept unopened until preflight is READY_FOR_CONFIRMATION: 6001+2i for i=0..25 (26 fresh roots), each with 256 paired-z task evaluations (128 first-cue source pairs) and 128 independent donor pairs. These roots are procedurally withheld by experiment stage; no claim of cryptographically concealed seeds.

Scientific minimum donor effect is 0.15 absolute probability; score quantization is 1/128; independent sham floor is the *sample maximum* absolute random-vs-random per-root difference across 59 calibration worlds, providing a nonparametric upper tolerance bound for a population 95th percentile at >=95% confidence under independent-world assumptions. Effective mechanistic threshold=max(.15,sham_floor,1/128). EvalMath `preflight.py --pilot .. --strict` must report READY_FOR_CONFIRMATION using the eight excluded development-world paired effects, 59 separate matched sham effects, two registered comparisons, α=.05, target effect .30, 26 planned confirmation roots and heldout_sealed=true (meaning no confirm roots scored). If not READY, do not open any confirmation roots. Exact probability statements are scoped to the synthetic generator family and its random initialization distribution.

A confirmatory positive requires: (i) root-level primary difference > effective threshold on enough of 26 roots to give one-sided exact sign p<=.025 (Bonferroni family of two comparisons), plus a 97.5% one-sided cluster bootstrap lower bound for mean primary effect > threshold; (ii) second registered feedback-versus-frozen root-level difference >0 at exact one-sided sign p<=.025 (report whether it passes separately); (iii) at least 80% of confirmation roots with teacher, full BPD and adaptive gate final-task accuracy >=.90 and adaptive mean active slots <=7.0/8; and (iv) engineering parity <=1e-5, per-pair equal-dose error <=1e-5 and no accidental test-set reuse. ## Gauge, limitations and security

Apply fixed invertible shears R1=[[1,.6],[0,1]] on the leading pair and R2 mixing components 0,2. Verify raw full VU invariance (<=2e-6) while hard singleton/component masks generally change. Re-SVD from the transformed full operator, rerun **fixed** and **feedback** mask trajectories, and require <=1e-5 parity when all nonzero singular-value gaps >.001; otherwise report degeneracies. The learned synthetic parity function remains solvable by a symbolic exact solver. First-stage four-component execution is dense; only second-stage execution is adaptive and sparsified. This study cannot certify SAE mechanism recovery in actual 7M/TRM checkpoints or nonlinear topology beyond the specified rank-four tanh system.
