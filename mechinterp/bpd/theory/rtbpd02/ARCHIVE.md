The replay reads the eight existing focused CAL roots in both worlds at the initial last-prompt token, passes 1 and 2, physical layer 21. Each of the two backends supplies a 10,752-coordinate down-projection input, a 3,072-coordinate native write, and a 3,072-coordinate raw post-layer carrier for each case and pass. COMP14 captured these values at the first generation step with batch size one. The public roster supplies selection and slot identity. Only selected case and state payloads are opened. The corresponding terminal audit anchors the hashes and completed coverage for the original source. The replay verifies the initial token-list digest from the original tokenizer receipt, the case, and the capture length.

Use the SHA-locked local LoopedTransformers archive tree and the original snapshot directory. The runner checks pinned source and audit hashes, world pairing, backend, target parameter identity, pass, layer, vector shape, checkpoint revision, and separate BF16 and NF4 IO18 fit qualifications. It checks both IO18 trajectories against the common initializer and original all-one full-head and boundary-state bitwise receipts. The eight T2 atoms define the target sum for compression. The source model's physical down-projection is larger and has a separate closure check.

The BF16 replay streams both pinned shards through read-only handles and reads the requested affine and RMSNorm tensors with NumPy. It publishes bitwise match counts and numerical deviations of a specified CPU emulation against the original captured BF16 native writes. The archived all-one native qualification and the CPU emulation are separately identified. The fixed pass-1 K reader is the derivative of the continuous two-RMSNorm map at the train-fold mean carrier followed by the pinned K projection. Heldout worlds in a root stay together, and CAL exposures predate these folds. The K tangent measures a local reader coordinate and is upstream of attention, recurrence, and answer scoring.

Run the optional replay with archive and snapshot paths and a fresh output directory outside both input trees.

Admission requires at least 5 GiB of available physical memory. The single-thread process uses below-normal priority, a 4 GiB system reserve, a 512 MiB process-private limit, and a 420 second wall limit. The runner does not load a decoder runtime. The BPD report can publish the aggregate and EvalMath decision. Raw vectors, model weights, fitted factors, prompt text, and token IDs stay on the local host.

## Data needed for future native validation

A separately authorized CAL export sufficient to extend this analysis should be immutable, hash-addressed, and documented before any model run. Each record would bind checkpoint and backend build, physical parameter and quantization state, tokenizer revision and input token-list digest, root/world/split, semantic token position, pass, module path, tensor side, dtype, dimensions, physical coordinate-frame identifiers, and capture or patch hook version. Both worlds of one root must appear in the same split. A source whitelist must select CAL independently of any protected test file. A run receipt should account for every selected root and the wire-level tensor digest of every export.

For native NF4 affine and future-reader closure, provision the effective per-occurrence layer-21 down-projection and layer-0 K operator with its quantization specification, stored packed weights, dequantization scales and metadata, operand, accumulation and output dtypes, and the actual kernel or a numerically qualified implementation. Include matching archived module inputs and outputs and original all-one full-head and boundary-state parity. This makes the handling of axes in the NF4 backend checkable and enables a measured error bound. The BF16 checkpoint projection can serve as a separate baseline for a question about precision differences.

For native causal transport, capture recipients' pre-edit states and donors' aligned write contrasts. Lock the outcome direction and independent exposure plan before model execution. Verify exact unmasked full-head parity and the projection-specific all-one and zero-gate controls, measure the physical displacement and state radius at the actual site, and register equal-dose random, source-swap, and sign controls. Capture downstream Q/K/V and residuals as needed for the registered reader and record signed source-specific answer effects and correctness, including recovery and corruption. A delayed or joint rescue claim requires matched single- and joint-path interventions. Use a fresh authorized root population for causal inference and a separately calibrated matched-sham tolerance bound.
