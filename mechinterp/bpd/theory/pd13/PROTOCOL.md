# BPD-PD-13 | Recovering clustered 16D sources with priority-ordered Givens search

**Prospective registration, November 18, 2026.** [CONFIG.json](CONFIG.json) was committed first at 9587e3a25f20aab20f96062f312af5f236242a08, before any PD-13 model optimization. It fixes all 32 fresh source rotations, the two 16D source cells, candidate counts, scoring criteria and statistical claims. The implementation must conform to the registration. The first scientific result remains frozen whether it passes or fails.

## Why this experiment

[PD-12](../pd12/RESULTS_20261118.md) established a matched-budget advantage of global-angle Givens search over local-angle search in 8D/16D but **failed its preregistered absolute recovery gate**. Its global37 search recovered 0/8 clustered strong-margin 16D sources and 0/8 clustered weak-margin 16D sources, despite a 100%-successful planted-Q oracle. The clustered source selected particular contiguous support motifs with probability 0.85, making coactive latent groups highly redundant. The earlier optimizer visited read pairs lexicographically and fit only 256 trajectories per rotation.

PD-13 tests whether pair-order selection guided by the currently *worst* smoothed read directions helps the same 16D global angular search recover reusable components. Separately, it tests whether an eightfold larger source sample helps under both priority and lexicographic ordering.

The main comparison isolates **pair order** while holding the sample size, random orthogonal starting basis, observed training boards, smoothing width, number of sweeps and candidate-angle evaluations fixed. A larger training sample is an independently crossed factor, reported as secondary.

## Exact source, independent units and holdouts

Import the *unchanged* [PD-12 source generator](../pd12/experiment.py), its seeded QR rotations, support banks, model builder, assignment routine and physical evaluator. Dimension is **16** in every arm. Each latent source pass has one to four active coordinates, balanced independent signs, and the original PD-12 "clustered" support law: at k≥2, choose an allowed anchored contiguous k-window with probability .85, otherwise choose among all training-allowed k-subsets; singletons remain uniform. Its forbidden antipodal pairs, stride-two triples and quartets never enter training.

The two source conditions are the original PD-12 settings: *strong margin* with active magnitude uniform on [0.75,1.25], training σ=.15 and hard read threshold .375; *weak margin* with magnitude uniform on [.25,1.25], training σ=.05 and threshold .125. Each contains **16 previously unused model/rotation seeds**. Their exact lists are in CONFIG, giving 32 independent statistical units.

For each seed, generate **one fixed 2048-board training pool** using the PD-12 generator with seed 100000+model_seed. The 256-board arms use exactly the first 256 complete trajectories of this same pool. This nesting is intentional: all four trained arms have the *same prefix* and the same sampled source Q, so sample-volume differences are controlled within each seed. Every optimizer receives **only the observed dense x**, with no latent support, source Q, cardinality or family labels. Q and support masks exist only inside the source generator and the held-out evaluation.

The original eight PD-12 evaluation strata are unchanged, with 96 four-pass trajectories each and RNG 200000+seed+10000×family-index: seen k1,k2,k3,k4; unseen k2,k3,k4; and a transition using previously withheld combinations. Held-out data are generated **after** search and cannot affect pair ordering, smoothing selection or stopping.

## Pair search, budget and matched controls

Maintain a 16×16 orthogonal V from the frozen random initialization generated by deterministic-sign QR with seed 610000+model_seed. Its decoder U is Vᵀ. Run exactly **three sweeps over all 120 unordered column pairs**, evaluating **37 angles from −90° through +90° inclusive** for each pair. Every candidate's Gaussian near-zero score and tie rule are *identical* to PD-12, at the registered margin-specific σ. At the winning angle, apply the Givens rotation to both physical read factors and their cached training projections. Zero angle remains a candidate so every accepted update is nondecreasing for its pair score.

The preregistered **pair-priority rule** uses the currently learned read coefficients \(z=xV\) from the same training data. At the *start* of each sweep, compute each column's marginal near-zero mass

\[
m_j = \frac1N \sum_{n=1}^{N}\exp[-z_{nj}^2/(2\sigma^2)].
\]

Rank every pair (i,j) with i<j by **ascending \(m_i+m_j\)**. This visits the least sparse-looking reads first, which may break up mixed read pairs before processing well-identified directions. Ties are resolved lexicographically by (i,j). Compute the ordering once per sweep and visit each of the same 120 pairs exactly once. It uses only observed x and the current V; it does not use Q, source labels or test outcomes.

The lexicographic control visits (0,1),(0,2),…,(14,15) each sweep, as in PD-12. It skips the priority computation by construction. Its angle grids, score evaluations and source samples are otherwise matched. The extra marginal-mass calculation in the priority arm is logged as a separate computation cost; exact **candidate-angle evaluation counts are equal**.

The five frozen arms are:

| Arm | Pair order | Train boards | Candidate angle scores |
|---|---|---:|---:|
| **priority2048 (primary)** | Least marginal zero mass first | 2048 | **13,320** |
| **lex2048 (primary control)** | Lexicographic | 2048 | **13,320** |
| priority256 | Least marginal zero mass first | 256-board prefix | **13,320** |
| lex256 | Lexicographic | 256-board prefix | **13,320** |
| planted_Q_oracle | True hidden Q supplied | 0 | 0 |

A 2048-board source yields 8192 observed pass vectors, giving **109,117,440 candidate-by-vector evaluations** for each high-volume search. The 256-board source gives 1024 vectors and **13,639,680**, an eightfold difference. Count marginal-proxy evaluations, measured CPU wall time, and source-drawing cost alongside candidate scores. Their computational budgets are matched **for the primary pair at 2048**, while the volume comparison deliberately changes scalar-score cost.

The planted oracle uses exact true Q, is explicitly privileged, and only verifies source/evaluator correctness. It is never counted as unlabelled mechanism discovery.

## Physical intervention and frozen scoring

After Givens search, install V, U=Vᵀ into the original shared 16D BPDModel/TiedComponentLinear identity teacher. Pass through the four tied physical calls with a zero residual delta mask, zero ablation and no sphere rescale. Infer by the **fixed exact 0/1 read threshold** set in PD-12 for the cell. There is no later gate fitting. Match learned read directions to Q using the same deterministic optimal assignment and **one permutation shared across all eight source families**.

A model seed passes only if mean absolute read cosine≥.90, mean held-out MSE≤.035, each family MSE≤.05, exact full-four-pass component support≥.80 in every seen family and ≥.70 in every unseen family, all masks binary and at least one nonzero pair update. The planted oracle is exempt only from the update requirement.

The **primary registered claim** is priority2048 over lex2048 in paired 16D clustered seeds. A scientific PASS requires (a) priority2048 to succeed in ≥18/32 independent models, (b) ≥8 net priority-only paired wins and (c) exact two-sided McNemar \(p\le .05\). Strong/weak margin subsets are reported separately, with n=16 each. Wilson 95% intervals and every seed-level result are retained.

The **secondary sample-volume comparisons** are priority2048 vs priority256 and lex2048 vs lex256 on matched seed Q and a nested data prefix. Report their outcomes, per-family support, exact paired contingency counts and runtime, without retroactive significance thresholds or claims of independent units.
