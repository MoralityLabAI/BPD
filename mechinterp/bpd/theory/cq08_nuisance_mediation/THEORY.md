# CQ-08: causal mediation on a legitimate recurrent input state

Let F_W(s,u)=tanh([s,u]W+b), with physical W of rank ≤8 and shared across two calls. The generator provides u_0=(x,y,n_1,n_2,0,-1) and u_1=(0,0,0,0,z,1). The first state s_1=F_W(0,u_0) is an actual image of the source manifold. The labels L_1=sgn(xy) and L_2=sgn(xz) are independent of all BPD factors. A donor maps (x,y) to (-x,-y), preserving L_1 while reversing L_2. The first step has no z; paired ±z with fixed u_0 proves a myopic 50% ceiling on the second label.

For each root, a physical model is trained with an explicitly separated 12-dimensional nonlinear task core and 24-dimensional nonlinear nuisance encoder. Its nuisance map is rank two, and nuisance input alternatives follow legal generator coordinates. The source-matched control keeps x,y fixed and changes only n_1,n_2 before calling F_W. The matching statistic uses d(s_n,s_r) and the first head h(s_n), with donor distance d(s_d,s_r) and recipient head h(s_r). Those two measured quantities may determine which nuisance source gets chosen; the target sign of the second visit is excluded from selection. This control holds the target x sign constant by construction.

The trained BPD decomposition W_hat=VU has C=8 components. Full-capacity executions preserve the physical operator after a double-precision canonical SVD refactor. A second-pass hard mask m∈{0,1}^8 computes F_m(s,u)=tanh((([s,u]V)⊙m)U+b). A rank-two component-off mask has exactly six active components. Two uniformly sampled random rank-two-off masks have identical active component counts and the same legitimate donor-state input. Their omitted write norms ||(([s_d,u_1]V)⊙(1-m))U|| may differ, so comparisons identify **cardinality-matched** mediation unless a separate dose-matched experiment is conducted.

Calibration selects the two canonical components whose independent calibration ablation maximizes L_2 softplus loss. Let Y_d denote the true delayed donor target and G denote joint feasibility from input-level nuisance matching plus clean first-head equality. Define D_m = 1{G and full-donor correct and masked donor incorrect}, scoring zero on unmatched pairs. The per-root causal contrast E[D_selected-D_random1] is measured over the *full generated donor-pair population*. If matching fails, both arms carry the failure in their denominator. Under controlled calibration and held-out donor inputs, a positive effect means the selected component block contributes more to the learned second-step computation than an equal-cardinality random block under this synthetic generator. It is basis-dependent and supported by calibration selection, and its random-control tail must be independently calibrated.

For any invertible R∈GL(8), (VR)(R^-1 U)=VU, while generally (VR) D_m (R^-1 U) differs from V D_m U. If nonzero singular values are distinct, canonical full-product SVD recovers the same rank-one operator terms up to joint sign flips. CQ-08 audits prescribed shears and near-degenerate gaps without claiming an intrinsic coordinate system where singular values coincide. The candidate source-state reachability is exact from the full teacher forward equation, while nearest finite-bank distances only describe the search mechanism. Masked *outputs* of F_m need not belong to the original reachable manifold.

All 128 test pairs per trained root are repeated measurements of one independently fitted world. The strict EvalMath planning gate requires a 95th-percentile/95%-confidence nonparametric sham bound from at least 59 independent roots, a separate prospective confirmation roster, familywise adjustment for two comparisons, and a meaningful +15 percentage-point floor. A successful engineering gate permits sham collection; it never justifies a confirmatory claim.
