## Independent world, task and known architecture

The independent experimental root consists of a seed-trained nonlinear recurrent physical operator, a separately trained BPD decomposition, calibration-only component selection, and its nuisance-source world. Each root uses an independent seeded generator and model fit. Eight development roots are `1301,1303,1307,1319,1321,1327,1361,1373`. The independently preregistered sham-calibration roots are `9001+2i` for `i=0..58` (**59**); prospective confirmation roots are `11001+2i` for `i=0..31` (**32**, subject to strict preflight power). No confirmation is enabled until an explicit release lock is committed.

Continuous first cue: `(x,y,n1,n2,0,-1)`. Second cue: `(0,0,0,0,z,1)`, with signs x,y,z independent fair and magnitudes in [.65,1.20]. Both nuisance coordinates are uniform [-2,2]. Independent target labels: `L1=sgn(x*y)`, `L2=sgn(x*z)`. The second cue is unavailable at first pass; use fixed paired-z cases to verify that any deterministic first-cue-only L2 classifier has ceiling 50%. The exact solver is an algebraic task ceiling.

The trained physical two-pass recurrence has D=36 hidden coordinates, a shared nonlinear `tanh` operator of rank at most eight, and a linear first/second head that reads the first 12 task coordinates. The remaining 24 coordinates are deliberately reserved for nuisance motion. There are **structurally disconnected core and nuisance blocks**: rank-six nonlinear core (12 state dimensions plus x,y,z,phase), and rank-two nonlinear nuisance encoder (24 state dimensions plus n1,n2). This deliberately constructed inductive bias is part of the experimental scope and limits generalization to unconstrained model representations. Fit the physical weights jointly for exactly 1,050 Adam steps, LR .018, batch 128, fresh generator seed offset +20000+i. Loss: two-readout softplus binary loss; .5 MSE nuisance hidden against seeded `tanh(n @ mapn)` feature targets; .5 first-head logit invariance MSE under simultaneous sign flip x→-x,y→-y; .25 flipped-source two-readout binary loss with L2 reversed; and .0004 component L2 regularizer. A flipped source changes second target while preserving the first. Avoid filtering or replacing any seed.

Freeze teacher. Fit an independent rank-eight BPD `V[42,8],U[8,36]` against the full teacher operator and first/second clean trajectories for exactly 650 Adam steps, LR .05, batch 96, seed offset +240000+i, using first-/second-state core MSE, first-/second-state nuisance MSE and full-matrix MSE, all coefficient 1. Canonicalize the **full** `VU` by double-precision SVD. All BPD masked execution uses actual `BPDModel/TiedComponentLinear` with residual contribution mask zero and `PassMaskSchedule` at pass two; exact first-pass states are taken from the frozen unmasked physical teacher.

## Calibration selection and fixed interventions

Calibration-only examples: 256 new labeled source cases per model root, generator seed offset +610000. For each of eight canonical component positions, turn off that singleton at *second pass* and calculate mean `softplus(-L2 * logit)`. Select the **two** components with the largest loss (stable tie by index). The chosen pair is then frozen for donor testing. This is supervised calibration selection of an already basis-dependent block. Source/test donor labels never enter selection.

The donor cohort has exactly 128 pairs per root, generator offset +811000, with first cues sharing n1,n2 and magnitudes but donor `(x,y)→(-x,-y)`, preserving L1 and reversing L2. The actual donor and recipient first states are each computed by the unmasked physical teacher from valid first inputs. Every pair enters the primary ITT denominator, including failed task eligibility or nuisance matching.

A second, **true reachable nuisance-source control** holds x,y exactly at recipient values, changes only nuisance inputs, and recomputes its full first state through the frozen physical teacher. Search exactly **512** seeded nuisance candidates per donor pair, offset +812000, using only state distance to recipient and initial head logits. Retain the best candidate satisfying `| ||s_null-s_rec|| - ||s_donor-s_rec|| | <=.25` in actual state Euclidean norm and `|head(s_null)-head(s_rec)| <=.5`; also require the clean donor vs recipient first-head logit difference <=.5 and matching L1 signs. Choose by normalized distance plus head discrepancy; ties by candidate enumeration. No second-target label, component mask or downstream behavioral score is consulted for matching. Unmatched pairs remain in the ITT denominator and count as 0 for all scored mediation arms. Frozen engineering feasibility gate: **>=80% jointly matched pairs per independent development root**, first target preserved, nuisance-source x-sign unchanged and zero state-range violations. If the gate fails, block sham and confirmation and preserve all failures.

## Primary mediation estimand and controls

On each **same naturally reachable donor first state**, execute one second recurrent visit with the donor's same z cue. Full eight-component execution is the donor ceiling. The selected rank-two **block-off** mask retains six of eight components. Two independently seeded uniform random rank-two block-off controls also retain six components; per-pair seeds offsets +850000 and +850001. These have **identical component-cardinality / execution budgets**. Their physical write-displacement norms need not match and must be reported; no claim of equal ablation physical dose is authorized by cardinality matching. Nuisance-source control is matched on **physical source-state displacement dose** within the registered .25 bin. It retains the recipient x sign and should predict the recipient's L2 rather than donor L2. Record that wrong-branch rate, and separately record its accuracy on its own label.

For full-clean-correct, jointly source-matched donor pairs, define `damage(block) = 1` if an ablated second-pass donor output becomes wrong for the independently generated donor L2. For missing matches, or full donor incorrect, set every arm's damage to zero without replacement. The primary model-root effect is `E[damage(selected)-damage(random1)]` over **all** 128 generated pairs; the second preregistered comparison uses `random2`. Minimum scientific effect is +0.15 absolute donor-correct-cell damage probability above the sham envelope. For non-Gaussian root effects, use independent-root sign and interval estimates with Holm over the two comparisons; preserve and report every seed, zero-difference root and negative arm. Also report full donor accuracy and first-head parity, two-readout accuracy, nuisance-source matched dose distribution, rank cost, raw ablated preactivation write norm distributions, and task-only vs nuisance-only predictor ceilings.

## Geometry and gauge audits

Every tested *intermediate input state* must equal a physical teacher forward pass from one legal first cue (max coordinate replay error <=1e-6), and must lie in [-1,1]^36 without post-hoc clipping or readout projection. This is the natural-state claim. Masked second-pass outputs are intervention-generated and are **not** claimed naturally reachable.

Apply two fixed nonsingular GL(8) shears to the full `VU`; ensure exact full-operator equality <=2e-6, then SVD recanonicalization mask parity <=1e-5 when minimal relevant nonzero singular gap >=.001. Report nearly repeated singular values and masks that change under raw shears. Native vs independent second-pass execution must agree <=1e-5 for full, selected and both random arms, with exact integer counts.

## EvalMath / release policy

Development results expose eight independently trained roots, with 128 repeated donor pairs per root. The strict EvalMath `preflight.py` requires >=8 development roots, a nonparametric 95th-percentile/95%-confidence sham tolerance bound from **59 independent** development/sham worlds, a measurement resolution at least 1/128, 2 registered comparisons, α=.05, scientific effect .15 and a new separately sealed confirmation cohort. The sham-world measurement is the worst absolute difference in donor-damage rates between **two independent random rank-two ablations** on the same root, at the common source-matched feasibility gate. Preflight planning target .30. A `READY_FOR_CONFIRMATION` result is a planning gate and never itself proves the mechanism. Confirmation must be explicitly unlocked after source-locked sham receipts, a complete root-power analysis and frozen source SHA verification. Keep all losing arms, matching failures, and independent source hashes in write-once JSON artifacts.

Claim scope: synthetic partly observed parity with a deliberately separated learned nuisance carrier, causal intervention at a naturally reachable input to the second visit, calibrated basis-specific BPD mediation. No claim about pretrained language models, arbitrary GL(8)-invariant singleton features, or naturally reachable **masked outputs**.
