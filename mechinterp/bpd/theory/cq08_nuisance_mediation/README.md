# BPD-CQ-08: reachable-state BPD component mediation

The experiment replaces CQ-07's generally unreachable hidden-state patches with **full, naturally reachable first-pass states** generated by the learned physical recurrent model. Its next visit runs through a separately learned BPD read/write operator. A calibration-selected two-component hard mask is ablated and compared against two independent uniform two-component ablations at the **same execution cost**. An independent nuisance-only input-space source provides a matching current-head/state-distance control without changing the answer branch.

Source and comparison protocol: [PROTOCOL.md](PROTOCOL.md). Development findings: [RESULTS.md](RESULTS.md). The scientific evidence class is **engineering development until a 59-independent-world matched sham calibration and prospective confirmation release**. No released confirmation outcomes currently exist.

The synthetic teacher has two *structurally separated* nonlinear recurrence channels: a rank-six task core with 12 state coordinates and a rank-two nuisance encoder with 24 state coordinates. Joint training learns both. The large nuisance carrier makes a clean source motion capable of matching donor state distance without necessarily changing the task bit. That design supplies a controlled feasibility test and does not imply the same geometry emerges in an unconstrained learned RMP/TRM.

The donor flips x and y signs together, so the first answer sign(xy) remains fixed while the delayed sign(xz) reverses. The second cue supplies z only after the first recurrent visit. Every evaluated first state is a full physical teacher output from a legal cue. The ablation happens *during* the second visit: masked outputs are computational interventions, and their natural-state reachability is not assumed.

Development-only runs from the BPD repository root:

```sh
python -m unittest discover -s mechinterp/bpd/theory/cq08_nuisance_mediation/tests -v
python -m mechinterp.bpd.theory.cq08_nuisance_mediation.reference --backend independent --check
python -m mechinterp.bpd.theory.cq08_nuisance_mediation.reference --backend native --check
python -m mechinterp.bpd.theory.cq08_nuisance_mediation.power \
  --development mechinterp/bpd/theory/cq08_nuisance_mediation/results/development.json \
  --strict
```

The strict preflight exits with a nonzero code until 59 independently trained sham roots are provided. The confirmation entry point requires a separate explicit `CONFIRM_UNLOCK.json` and remains sealed; the verifier adds an additional fail-closed gate regardless of that file. The 59-root sham stage is separately staged and write-once, with a fixed roster distinct from development and confirmation. See the GitHub Actions workflow for reproducible independent and native developer parity.

At current development status, 8 fresh trained model roots and 1,024 donor pairs passed the source-matching feasibility gate. All five original pilot roots and all later development roots remain in the frozen receipt, including the weaker one. All 2,048 paired-z task scores reproduce. The two random ablation arms were sampled independently and scored on the same source states; their *actual ablation write norms* are recorded separately. Control matching conditions on observed head and source-state distance alone, never on donor L2 or ablation outcomes.
