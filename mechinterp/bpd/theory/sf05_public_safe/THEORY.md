# SF05 mathematical controls: a public-safe tangent intersection

**Exact linear algebra / finite-dimensional theorem.** This applies to the actual SF04 scalar readout \`q(h)=h[0]\` and to a differentiable, scalar *future public* map \`G_U(h)=q(F(h,x_U))\`.

Set \`Q=e_0^\top\`, \`K_0=ker Q\`, and let \`g=P_{K_0}∇G_U(h)\`. The public-safe subspace at the chosen state is

\[
K=K_0\cap\ker DG_U(h).
\]

For any candidate \`d\`, first remove its current-readout component, \`d_0=P_{K_0}d\`. If \`g\ne0\`, the unique Euclidean closest vector in \`K\` is

\[
d_{\rm safe}=d_0-\frac{g^\top d_0}{g^\top g}g.
\]

For \`g=0\`, \`d_{\rm safe}=d_0\`. The proof is orthogonal decomposition: \`K_0=span(g)\oplus K\` whenever \`g\ne0\`; the scalar projection removes precisely the one-dimensional forbidden component. Since \`d_{\rm safe}\in K\`, it conserves the full current readout (exactly, because SF04 \`q\` is linear), and makes the **first-order** public future change vanish. It is also the minimum-L2 correction to the candidate edit satisfying these two constraints.

Let \`a=P_K∇G_A(h)\` for a *different* authorized future query. Cauchy–Schwarz and attainability at \`v=\rho a/\|a\|\` give

\[
\max_{\substack{v\in K\\ \|v\|\le\rho}}|DG_A(h)v|=\rho\|a\|.
\]

This is an optimum of the *local linearized authorized response*, with a privileged oracle knowing the true future-gradient; it does not imply global authorized output transfer or source binding. A random public-safe matched-norm edit chooses a vector in \`K\` with the same L2 dose as the selected candidate. A **signed-authorized-gradient matched** edit further fixes \`∇G_A(h)^\top v\` to match that candidate. Any selected-component advantage against this privileged control requires a genuinely finite-radius or higher-order effect.

## Why tangent safety needs a finite-radius audit

If \`G_U\` has Hessian operator norm bounded by \`M\` along the edit segment, Taylor's remainder gives

\[
|G_U(h+d_{\rm safe})-G_U(h)|\le \tfrac12 M\|d_{\rm safe}\|^2.
\]

The inequality is conditional on such a bound, which the SF04 teacher experiment does **not** certify. A counterexample is \`G_U(h_0,h_1,h_2)=h_0+h_1^2\` at \`h=(0,0,0)\`. Its current readout is \`q(h)=h_0\`, its projected public gradient vanishes, and \`d=(0,0.2,0)\in K\` changes the finite public future by exactly \`0.04\`. The source-only unit test preserves this distinction.
