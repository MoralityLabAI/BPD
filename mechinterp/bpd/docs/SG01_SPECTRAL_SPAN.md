# SG-01: spectral span

Companion to [SG-01](https://github.com/MoralityLabAI/Compactification-Theory/pull/315). For sorted sites the range is a sum of gaps crossed by the selected subset. Independent Bernoulli gates give the product of left and right inclusion probabilities. The helper is O(T), exact for hard gates and independent soft gates. Empty/singleton widths are zero. Correlated soft gates need a different model. Coordinates and bit prices are assigned, not measured mutual information. A producer must be explicitly included if required. Opt in during development with lambda_geo * spectral_span_penalty(schedule.comp_mask, fixed_sites, assigned_bits). Existing training losses and confirmation seals unchanged. Register geometry-free, shuffled-coordinate and equal-budget controls, freeze lambda, geometry, candidates and dose, require matched realized displacement and head parity. Local CPU helper checks passed for 32 masks, soft enumeration/gradient agreement, schedule shape and bad inputs. Run python -m pytest mechinterp/bpd/test_spectral_span.py. Native causal validation pending.
